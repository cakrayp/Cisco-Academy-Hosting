Operasi dan Konfigurasi Pengalihan Lapisan 3

SVI adalah antarmuka virtual yang dikonfigurasi dalam saklar multilayer, seperti yang ditunjukkan pada gambar. SVI dapat dibuat untuk VLAN apa pun yang ada di switch. SVI dianggap virtual karena tidak ada port fisik yang didedikasikan untuk antarmuka. Ia dapat melakukan fungsi yang sama untuk VLAN seperti antarmuka router, dan dapat dikonfigurasi dengan cara yang hampir sama seperti antarmuka router (yaitu, alamat IP, ACL masuk/keluar, dll.). SVI untuk VLAN menyediakan pemrosesan Layer 3 untuk paket ke atau dari semua port switch yang terkait dengan VLAN tersebut.

Secara default, SVI dibuat untuk VLAN default (VLAN 10) untuk mengizinkan administrasi switch jarak jauh. SVI tambahan harus dibuat secara eksplisit. SVI dibuat saat pertama kali mode konfigurasi antarmuka VLAN dimasukkan untuk SVI VLAN tertentu, seperti saatantarmuka vlan 10perintah dimasukkan. Nomor VLAN yang digunakan sesuai dengan tag VLAN yang terkait dengan bingkai data pada trunk yang dienkapsulasi 802.1Q atau dengan ID VLAN (VID) yang dikonfigurasi untuk port akses. Saat membuat SVI sebagai gateway untuk VLAN 10, beri nama antarmuka SVI VLAN 10. Konfigurasikan dan tetapkan alamat IP untuk setiap VLAN SVI.

Setiap kali SVI dibuat, pastikan bahwa VLAN tertentu ada di database VLAN. Pada gambar, switch harus memiliki VLAN 10 dan VLAN 20 yang ada di database VLAN; jika tidak, antarmuka SVI tetap tidak aktif.

Berikut ini adalah beberapa alasan untuk mengkonfigurasi SVI:

  • Untuk menyediakan gateway untuk VLAN sehingga lalu lintas dapat dirutekan masuk atau keluar dari VLAN tersebut

  • Untuk menyediakan konektivitas IP Layer 3 ke switch

  • Untuk mendukung protokol routing dan konfigurasi bridging

Berikut ini adalah beberapa keuntungan dari SVI (satu-satunya kelemahan adalah bahwa switch multilayer lebih mahal):

  • Ini jauh lebih cepat daripada router-on-a-stick, karena semua perangkat keras dialihkan dan dirutekan.

  • Tidak diperlukan link eksternal dari switch ke router untuk routing.

  • Tidak terbatas pada satu tautan. Layer 2 EtherChannels dapat digunakan di antara switch untuk mendapatkan lebih banyak bandwidth.

  • Latensinya jauh lebih rendah, karena tidak perlu keluar dari saklar.
