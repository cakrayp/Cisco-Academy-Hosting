Konfigurasikan Perutean Antar-VLAN Lama

Perutean antar-VLAN lama mengharuskan router memiliki beberapa antarmuka fisik. Router menyelesaikan perutean dengan menghubungkan setiap antarmuka fisiknya ke VLAN unik. Setiap antarmuka juga dikonfigurasi dengan alamat IP untuk subnet yang terkait dengan VLAN tertentu yang terhubung dengannya. Dengan mengkonfigurasi alamat IP pada antarmuka fisik, perangkat jaringan yang terhubung ke masing-masing VLAN dapat berkomunikasi dengan router menggunakan antarmuka fisik yang terhubung ke VLAN yang sama. Dalam konfigurasi ini, perangkat jaringan dapat menggunakan router sebagai gateway untuk mengakses perangkat yang terhubung ke VLAN lainnya.

Proses perutean memerlukan perangkat sumber untuk menentukan apakah perangkat tujuan bersifat lokal atau jauh ke subnet lokal. Perangkat sumber menyelesaikan hal ini dengan membandingkan alamat IP sumber dan tujuan dengan subnet mask. Ketika alamat IP tujuan telah ditentukan berada di jaringan jarak jauh, perangkat sumber harus mengidentifikasi ke mana ia perlu meneruskan paket untuk mencapai perangkat tujuan. Perangkat sumber memeriksa tabel perutean lokal untuk menentukan ke mana ia perlu mengirim data. Perangkat menggunakan gateway defaultnya sebagai tujuan Lapisan 2 untuk semua lalu lintas yang harus keluar dari subnet lokal. Gateway default adalah rute yang digunakan perangkat ketika tidak ada rute lain yang ditentukan secara eksplisit ke jaringan tujuan. Alamat IP antarmuka router pada subnet lokal bertindak sebagai gateway default untuk perangkat pengirim.

Ketika perangkat sumber telah menentukan bahwa paket harus berjalan melalui antarmuka router lokal pada VLAN yang terhubung, perangkat sumber mengirimkan permintaan ARP untuk menentukan alamat MAC dari antarmuka router lokal. Ketika router mengirimkan balasan ARP-nya kembali ke perangkat sumber, perangkat sumber dapat menggunakan alamat MAC untuk menyelesaikan pembingkaian paket sebelum mengirimkannya ke jaringan sebagai lalu lintas unicast.

Karena frame Ethernet memiliki alamat MAC tujuan dari antarmuka router, switch mengetahui secara pasti port switch mana yang meneruskan lalu lintas unicast untuk mencapai antarmuka router untuk VLAN tersebut. Ketika frame tiba di router, router menghapus informasi alamat MAC sumber dan tujuan untuk memeriksa alamat IP tujuan paket. Router membandingkan alamat tujuan dengan entri dalam tabel routingnya untuk menentukan ke mana ia perlu meneruskan data untuk mencapai tujuan akhirnya. Jika router menentukan bahwa jaringan tujuan adalah jaringan yang terhubung secara lokal, seperti halnya dengan routing antar-VLAN, router mengirimkan permintaan ARP keluar antarmuka yang terhubung secara fisik ke VLAN tujuan. Perangkat tujuan merespons kembali ke router dengan alamat MAC-nya, yang kemudian digunakan router untuk membingkai paket. Router kemudian mengirimkan lalu lintas unicast ke switch, yang meneruskannya keluar port tempat perangkat tujuan terhubung.

Klik tombol Putar pada gambar untuk melihat bagaimana perutean antar-VLAN lama dilakukan.

Meskipun ada banyak langkah dalam proses perutean antar-VLAN, ketika dua perangkat pada VLAN berbeda berkomunikasi melalui router, seluruh proses terjadi dalam sepersekian detik.
