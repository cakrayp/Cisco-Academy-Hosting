Konfigurasikan Perutean Antar-VLAN Router-on-a-Stick

Konfigurasi router berbeda ketika konfigurasi router-on-a-stick digunakan dibandingkan dengan perutean antar-VLAN lama. Gambar tersebut menunjukkan bahwa beberapa subinterface dikonfigurasi.

Setiap subinterface dibuat menggunakanantarmukaantarmuka_id subantarmuka_idperintah mode konfigurasi global. Sintaks untuk subinterface adalah antarmuka fisik, dalam hal ini g0/0, diikuti dengan titik dan nomor subinterface. Nomor subinterface dapat dikonfigurasi, namun biasanya mencerminkan nomor VLAN. Dalam contoh ini, subinterface digunakan 10 Dan 30 sebagai nomor subinterface untuk memudahkan mengingat VLAN yang terkait. Subinterface GigabitEthernet0/0.10 dibuat menggunakanantarmuka g0/0.10perintah mode konfigurasi global.

Sebelum menetapkan alamat IP ke subinterface, subinterface harus dikonfigurasi untuk beroperasi pada VLAN tertentu menggunakanenkapsulasi dot1qvlan_idmemerintah. Dalam contoh ini, subinterface G0/0.10 ditugaskan ke VLAN 10.

Catatan: Ada sebuahwarga asliopsi kata kunci yang dapat ditambahkan ke perintah ini untuk mengatur VLAN asli IEEE 802.1Q. Dalam contoh iniwarga asliopsi kata kunci dikecualikan untuk membiarkan VLAN asli default ke VLAN 1.

Selanjutnya, tetapkan alamat IP untuk subinterface menggunakanalamat IPip_address subnet_maskperintah mode konfigurasi subantarmuka. Dalam contoh ini, subinterface G0/0.10 diberi alamat IP 172.17.10.1 menggunakanalamat ip 172.17.10.1 255.255.255.0memerintah.

Proses ini diulangi untuk semua subinterface router yang diperlukan untuk merutekan antara VLAN yang dikonfigurasi pada jaringan. Setiap subinterface router harus diberi alamat IP pada subnet unik agar routing dapat terjadi. Misalnya, subantarmuka router lainnya, G0/0.30, dikonfigurasi untuk menggunakan alamat IP 172.17.30.1, yang berada pada subnet berbeda dari subantarmuka G0/0.10.

Setelah subinterface dikonfigurasi, subinterface harus diaktifkan.

Berbeda dengan antarmuka fisik, subantarmuka tidak diaktifkan dengantidak ada penutupanperintah pada tingkat mode konfigurasi subinterface perangkat lunak Cisco IOS. Memasukitidak ada penutupanperintah di tingkat subinterface tidak berpengaruh. Sebaliknya, ketika antarmuka fisik diaktifkan dengantidak ada penutupanperintah, semua subinterface yang dikonfigurasi diaktifkan. Demikian pula, jika antarmuka fisik dinonaktifkan, semua subantarmuka juga dinonaktifkan. Dalam contoh ini, perintahnyatidak ada penutupandimasukkan dalam mode konfigurasi antarmuka untuk antarmuka G0/0, yang pada gilirannya, mengaktifkan semua subantarmuka yang dikonfigurasi.

Subinterface individual dapat dimatikan secara administratif denganpenutupanmemerintah.
