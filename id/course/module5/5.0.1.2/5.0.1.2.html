Beralih ke Saluran Jaringan Lokal

Anda bekerja untuk bisnis skala kecil hingga menengah. Sebagai administrator jaringan, Anda bertanggung jawab untuk memastikan bahwa jaringan Anda beroperasi secara efisien dan aman.

Beberapa tahun yang lalu, Anda membuat VLAN di satu-satunya switch untuk dua departemen Anda, Akuntansi dan Penjualan. Seiring berkembangnya bisnis, menjadi jelas bahwa terkadang kedua departemen ini harus berbagi file perusahaan dan sumber daya jaringan.

Anda mendiskusikan skenario ini dengan administrator jaringan di beberapa cabang perusahaan Anda. Mereka meminta Anda untuk mempertimbangkan penggunaan perutean antar-VLAN.

Teliti konsep perutean antar-VLAN.

Rancang presentasi sederhana untuk menunjukkan kepada manajer Anda bagaimana Anda akan menggunakan perutean antar-VLAN untuk memungkinkan departemen Akuntansi dan Penjualan tetap terpisah, namun berbagi file perusahaan dan sumber daya jaringan.
