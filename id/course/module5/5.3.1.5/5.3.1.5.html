Operasi dan Konfigurasi Pengalihan Lapisan 3

Sakelar Catalyst 2960 dapat berfungsi sebagai perangkat Layer 3 dan merutekan antara VLAN dan sejumlah rute statis terbatas.

Cisco Switch Database Manager (SDM) menyediakan beberapa templat untuk switch 2960. Templat dapat diaktifkan untuk mendukung peran tertentu tergantung pada bagaimana saklar digunakan dalam jaringan. Misalnya, templat perutean lanbase sdm dapat diaktifkan untuk memungkinkan peralihan rute antar VLAN dan untuk mendukung perutean statis.

Pada Gambar 1,tunjukkan sdm lebih sukaperintah dimasukkan pada sakelar S1 dan templat default diterapkan. Templat default adalah pengaturan default pabrik untuk sakelar Catalyst 2960. Templat default tidak mendukung perutean statis. Jika pengalamatan IPv6 telah diaktifkan, templatnya akan menjadi dual-ipv4-dan-ipv6 default.

Templat SDM dapat diubah dalam mode konfigurasi global dengansdm lebih sukamemerintah.

Catatan: Pada Gambar 2, 4, 6, dan 7, do perintah digunakan untuk menjalankan perintah EXEC pengguna atau hak istimewa EXEC dari mode konfigurasi router lainnya.

Pada Gambar 2, opsi template SDM ditampilkan dengansdm lebih suka?memerintah. Template SDM diubah menjadi lanbase-routing. Peralihan harus dimuat ulang agar templat baru dapat diterapkan.

Pada Gambar 3, template perutean lanbase aktif di S1. Dengan templat ini, perutean statis didukung hingga 750 rute statis.

Pada Gambar 4, antarmuka F0/6 pada S1 ditugaskan ke VLAN 2. SVI untuk VLAN 1 dan 2 juga dikonfigurasi dengan alamat IP masing-masing 192.168.1.1/24 dan 192.168.2.1/24. Perutean IP diaktifkan denganperutean ipperintah mode konfigurasi global.
