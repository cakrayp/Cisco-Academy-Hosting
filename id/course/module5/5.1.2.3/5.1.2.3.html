Konfigurasi Perutean Antar-VLAN

Konfigurasikan Perutean Antar-VLAN Lama

Selanjutnya, router dapat dikonfigurasi untuk melakukan routing antar-VLAN.

Antarmuka router dikonfigurasi dengan cara yang mirip dengan mengkonfigurasi antarmuka VLAN pada switch. Untuk mengonfigurasi antarmuka tertentu, ubah ke mode konfigurasi antarmuka dari mode konfigurasi global.

Seperti yang ditunjukkan pada Gambar 1, setiap antarmuka dikonfigurasi dengan alamat IP menggunakanalamat IPip_address subnet_maskperintah dalam mode konfigurasi antarmuka.

Dalam contoh, antarmuka G0/0 dikonfigurasi dengan alamat IP 172.17.10.1 dan subnet mask 255.255.255.0 menggunakanalamat ip 172.17.10.1 255.255.255.0memerintah.

Antarmuka router dinonaktifkan secara default dan harus diaktifkan menggunakantidak ada penutupanperintah sebelum digunakan. Setelahtidak ada penutupanperintah mode konfigurasi antarmuka telah dikeluarkan, pemberitahuan ditampilkan, menunjukkan bahwa status antarmuka telah berubah ke atas. Ini menunjukkan bahwa antarmuka sekarang diaktifkan.

Proses ini diulangi untuk semua antarmuka router. Setiap antarmuka router harus ditetapkan ke subnet unik agar perutean dapat dilakukan. Dalam contoh ini, antarmuka router lainnya, G0/1, telah dikonfigurasi untuk menggunakan alamat IP 172.17.30.1, yang berada pada subnet berbeda dari antarmuka G0/0.

Setelah alamat IP ditetapkan ke antarmuka fisik dan antarmuka diaktifkan, router mampu melakukan perutean antar-VLAN.

Periksa tabel routing menggunakantampilkan rute ipmemerintah.

Pada Gambar 2, ada dua rute yang terlihat di tabel routing. Salah satu rutenya adalah ke subnet 172.17.10.0, yang terpasang pada antarmuka lokal G0/0. Rute lainnya adalah ke subnet 172.17.30.0, yang terpasang pada antarmuka lokal G0/1. Router menggunakan tabel perutean ini untuk menentukan ke mana harus mengirim lalu lintas yang diterimanya. Misalnya, jika router menerima paket pada antarmuka G0/0 yang ditujukan untuk subnet 172.17.30.0, router akan mengidentifikasi bahwa ia harus mengirimkan paket keluar antarmuka G0/1 untuk mencapai host pada subnet 172.17.30.0.

Perhatikan surat itu C di sebelah kiri setiap entri rute untuk VLAN. Surat ini menunjukkan bahwa rute tersebut bersifat lokal untuk antarmuka yang terhubung, yang juga diidentifikasi dalam entri rute. Dengan menggunakan keluaran dalam contoh ini, jika lalu lintas ditujukan untuk subnet 172.17.30.0, router akan meneruskan lalu lintas keluar antarmuka G0/1.
