Konfigurasi NAT

Penerusan Pelabuhan

Penerusan port (terkadang disebut sebagai tunneling) adalah tindakan meneruskan port jaringan dari satu node jaringan ke node jaringan lainnya. Teknik ini memungkinkan pengguna eksternal untuk mencapai port pada alamat IPv4 pribadi (di dalam LAN) dari luar, melalui router yang mendukung NAT.

Biasanya, program dan operasi berbagi file peer-to-peer, seperti layanan web dan FTP keluar, mengharuskan port router diteruskan atau dibuka agar aplikasi ini dapat berfungsi, seperti yang ditunjukkan pada Gambar 1. Karena NAT menyembunyikan alamat internal, peer-to-peer hanya bekerja dari dalam ke luar di mana NAT dapat memetakan permintaan keluar terhadap balasan yang masuk.

Masalahnya adalah NAT tidak mengizinkan permintaan dimulai dari luar. Situasi ini dapat diatasi dengan intervensi manual. Penerusan port dapat dikonfigurasi untuk mengidentifikasi port tertentu yang dapat diteruskan ke host dalam.

Ingatlah bahwa aplikasi perangkat lunak Internet berinteraksi dengan port pengguna yang harus terbuka atau tersedia untuk aplikasi tersebut. Aplikasi yang berbeda menggunakan port yang berbeda. Hal ini membuatnya dapat diprediksi bagi aplikasi dan router untuk mengidentifikasi layanan jaringan. Misalnya, HTTP beroperasi melalui port 80 yang terkenal. Ketika seseorang memasukihttp://cisco.comalamat, browser menampilkan situs web Cisco Systems, Inc. Perhatikan bahwa mereka tidak perlu menentukan nomor port HTTP untuk permintaan halaman, karena aplikasi mengasumsikan port 80.

Jika diperlukan nomor port yang berbeda, dapat ditambahkan ke URL yang dipisahkan dengan titik dua (:). Misalnya, jika server web mendengarkan pada port 8080, pengguna akan mengetikhttp://www.example.com:8080.

Penerusan port memungkinkan pengguna di Internet untuk mengakses server internal dengan menggunakan alamat port WAN router dan nomor port eksternal yang cocok. Server internal biasanya dikonfigurasi dengan alamat IPv4 pribadi RFC 1918. Ketika permintaan dikirim ke alamat IPv4 port WAN melalui Internet, router meneruskan permintaan tersebut ke server yang sesuai di LAN. Untuk alasan keamanan, router broadband tidak secara default mengizinkan permintaan jaringan eksternal apa pun untuk diteruskan ke host dalam.

Gambar 2 menunjukkan pemilik usaha kecil yang menggunakan server point of sale (PoS) untuk melacak penjualan dan inventaris di toko. Server dapat diakses di dalam toko, namun karena memiliki alamat IPv4 pribadi, server tidak dapat diakses publik dari Internet. Mengaktifkan router lokal untuk penerusan porta memungkinkan pemilik mengakses server tempat penjualan dari mana saja di Internet. Penerusan port pada router dikonfigurasi menggunakan nomor port tujuan dan alamat IPv4 pribadi dari server tempat penjualan. Untuk mengakses server, perangkat lunak klien akan menggunakan alamat IPv4 publik dari router dan port tujuan server.
