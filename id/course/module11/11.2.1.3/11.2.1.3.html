Konfigurasi NAT

Mengonfigurasi NAT Statis

Perintah yang berguna untuk memverifikasi operasi NAT adalahtampilkan terjemahan ip natmemerintah. Perintah ini menunjukkan terjemahan NAT aktif. Terjemahan statis, tidak seperti terjemahan dinamis, selalu ada di tabel NAT. Gambar 1 menunjukkan keluaran dari perintah ini menggunakan contoh konfigurasi sebelumnya. Karena contohnya adalah konfigurasi NAT statis, terjemahannya selalu ada di tabel NAT terlepas dari komunikasi aktif apa pun. Jika perintah dikeluarkan selama sesi aktif, outputnya juga menunjukkan alamat perangkat luar seperti yang ditunjukkan pada Gambar 1.

Perintah lain yang berguna adalahtampilkan statistik ip natmemerintah. Seperti yang ditunjukkan pada Gambar 2,tampilkan statistik ip natperintah menampilkan informasi tentang jumlah total terjemahan aktif, parameter konfigurasi NAT, jumlah alamat di pool, dan jumlah alamat yang telah dialokasikan.

Untuk memverifikasi bahwa terjemahan NAT berfungsi, yang terbaik adalah menghapus statistik dari terjemahan sebelumnya menggunakanhapus statistik ip natperintah sebelum pengujian.

Sebelum komunikasi apa pun dengan server web,tampilkan statistik ip natperintah tidak menunjukkan hit saat ini. Setelah klien membuat sesi dengan server web, filetampilkan statistik ip natperintah telah ditingkatkan menjadi lima pukulan. Ini memverifikasi bahwa terjemahan NAT statis terjadi di R2.
