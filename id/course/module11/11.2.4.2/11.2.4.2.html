Penerusan Pelabuhan

Gambar tersebut menunjukkan jendela konfigurasi Single Port Forwarding pada router Linksys EA6500 SOHO. Secara default, penerusan porta tidak diaktifkan di router.

Penerusan port dapat diaktifkan untuk aplikasi dengan menentukan alamat lokal di dalam tempat permintaan harus diteruskan. Pada gambar, permintaan layanan HTTP yang masuk ke router Linksys ini diteruskan ke server web dengan alamat lokal dalam 192.168.1.254. Jika alamat WAN IPv4 eksternal dari router SOHO adalah 209.165.200.225, pengguna eksternal dapat masukhttp://www.example.comdan router Linksys mengalihkan permintaan HTTP ke server web internal di alamat IPv4 192.168.1.254, menggunakan nomor port default 80.

Port selain port default 80 dapat ditentukan. Namun, pengguna eksternal harus mengetahui nomor port spesifik yang akan digunakan. Untuk menentukan port yang berbeda, nilai Port Eksternal di jendela Single Port Forwarding akan diubah.

Pendekatan yang diambil untuk mengonfigurasi penerusan porta bergantung pada merek dan model router broadband di jaringan. Namun, ada beberapa langkah umum yang harus diikuti. Jika instruksi yang diberikan oleh ISP, atau instruksi yang disertakan dengan router, tidak memberikan panduan yang memadai, situs webhttp://www.portforward.commenyediakan panduan untuk beberapa router broadband. Anda dapat mengikuti petunjuk untuk menambah atau menghapus port sesuai kebutuhan untuk memenuhi kebutuhan aplikasi apa pun yang ingin Anda izinkan atau tolak.
