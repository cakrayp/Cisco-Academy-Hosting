Konfigurasi NAT dan IPv6

NAT untuk IPv6 digunakan dalam konteks yang jauh berbeda dari NAT untuk IPv4. Variasi NAT untuk IPv6 digunakan untuk menyediakan akses secara transparan antara jaringan IPv6 saja dan jaringan IPv4 saja. Ini tidak digunakan sebagai bentuk terjemahan IPv6 privat ke IPv6 global.

Idealnya, IPv6 harus dijalankan secara native jika memungkinkan. Ini berarti perangkat IPv6 berkomunikasi satu sama lain melalui jaringan IPv6. Namun, untuk membantu perpindahan dari IPv4 ke IPv6, IETF telah mengembangkan beberapa teknik transisi untuk mengakomodasi berbagai skenario IPv4-ke-IPv6, termasuk dual-stack, tunneling, dan translasi.

Dual-stack adalah saat perangkat menjalankan protokol yang terkait dengan IPv4 dan IPv6. Tunneling untuk IPv6 adalah proses merangkum paket IPv6 di dalam paket IPv4. Hal ini memungkinkan paket IPv6 ditransmisikan melalui jaringan khusus IPv4.

NAT untuk IPv6 tidak boleh digunakan sebagai strategi jangka panjang, namun sebagai mekanisme sementara untuk membantu migrasi dari IPv4 ke IPv6. Selama bertahun-tahun, ada beberapa jenis NAT untuk IPv6 termasuk Network Address Translation-Protocol Translation (NAT-PT). NAT-PT sudah tidak digunakan lagi oleh IETF dan digantikan dengan NAT64. NAT64 berada di luar cakupan kurikulum ini.
