Konfigurasi NAT

Mengonfigurasi NAT Statis

NAT Statis adalah pemetaan satu-ke-satu antara alamat dalam dan alamat luar. NAT Statis memungkinkan perangkat eksternal untuk memulai koneksi ke perangkat internal menggunakan alamat publik yang ditetapkan secara statis. Misalnya, server web internal dapat dipetakan ke alamat global tertentu sehingga dapat diakses dari jaringan luar.

Gambar 1 menunjukkan jaringan dalam yang berisi server web dengan alamat IPv4 pribadi. Router R2 dikonfigurasi dengan NAT statis untuk memungkinkan perangkat di jaringan luar (Internet) mengakses server web. Klien di jaringan luar mengakses server web menggunakan alamat IPv4 publik. NAT Statis menerjemahkan alamat IPv4 publik ke alamat IPv4 pribadi.

Ada dua tugas dasar saat mengonfigurasi terjemahan NAT statis.

Langkah 1.Tugas pertama adalah membuat pemetaan antara alamat lokal dalam dan alamat global dalam. Misalnya, alamat lokal dalam 192.168.10.254 dan alamat global dalam 209.165.201.5 pada Gambar 1 dikonfigurasi sebagai terjemahan NAT statis.

Langkah 2.Setelah pemetaan dikonfigurasi, antarmuka yang berpartisipasi dalam terjemahan dikonfigurasikan sebagai di dalam atau di luar relatif terhadap NAT. Dalam contoh, antarmuka Serial 0/0/0 dari R2 adalah antarmuka dalam dan Serial 0/1/0 adalah antarmuka luar.

Paket yang tiba di antarmuka bagian dalam R2 (Serial 0/0/0) dari alamat IPv4 lokal yang dikonfigurasi (192.168.10.254) diterjemahkan dan kemudian diteruskan ke jaringan luar. Paket yang tiba di antarmuka luar R2 (Serial 0/1/0), yang dialamatkan ke alamat IPv4 global dalam yang dikonfigurasi (209.165.201.5), diterjemahkan ke alamat lokal dalam (192.168.10.254) dan kemudian diteruskan ke jaringan dalam.

Gambar 2 menguraikan perintah yang diperlukan untuk mengkonfigurasi NAT statis.

Gambar 3 menunjukkan perintah yang diperlukan pada R2 untuk membuat pemetaan NAT statis ke server web dalam contoh topologi. Dengan konfigurasi yang ditunjukkan, R2 menerjemahkan paket dari server web dengan alamat 192.168.10.254 ke alamat IPv4 publik 209.165.201.5. Klien Internet mengarahkan permintaan web ke alamat IPv4 publik 209.165.201.5. R2 meneruskan lalu lintas tersebut ke server web di 192.168.10.254.

Gunakan Pemeriksa Sintaks pada Gambar 4 untuk mengonfigurasi entri NAT statis tambahan di R2.
