Operasi NAT

Karakteristik NAT

Dalam contoh ini, PC1 dengan alamat pribadi 192.168.10.10 ingin berkomunikasi dengan server web luar dengan alamat publik 209.165.201.1.

Klik tombol Putar pada gambar untuk memulai animasi.

PC1 mengirimkan paket yang dialamatkan ke server web. Paket diteruskan oleh R1 ke R2.

Ketika paket tiba di R2, router berkemampuan NAT untuk jaringan, R2 membaca alamat IPv4 tujuan paket untuk menentukan apakah paket tersebut cocok dengan kriteria yang ditentukan untuk penerjemahan.

Dalam hal ini, alamat IPv4 sumber sesuai dengan kriteria dan diterjemahkan dari 192.168.10.10 (dalam alamat lokal) ke 209.165.200.226 (dalam alamat global). R2 menambahkan pemetaan alamat lokal ke global ke tabel NAT.

R2 mengirimkan paket dengan alamat sumber yang diterjemahkan ke tujuan.

Server web merespons dengan paket yang dialamatkan ke alamat global dalam PC1 (209.165.200.226).

R2 menerima paket dengan alamat tujuan 209.165.200.226. R2 memeriksa tabel NAT dan menemukan entri untuk pemetaan ini. R2 menggunakan informasi ini dan menerjemahkan alamat global dalam (209.165.200.226) ke alamat lokal dalam (192.168.10.10), dan paket diteruskan ke PC1.
