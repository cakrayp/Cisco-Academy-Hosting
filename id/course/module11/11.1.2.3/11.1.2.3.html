Operasi NAT

Jenis NAT

Port Address Translation (PAT), juga dikenal sebagai kelebihan NAT, memetakan beberapa alamat IPv4 pribadi ke satu alamat IPv4 publik atau beberapa alamat. Inilah yang dilakukan sebagian besar router rumah. ISP memberikan satu alamat ke router, namun beberapa anggota rumah tangga dapat mengakses Internet secara bersamaan. Ini adalah bentuk NAT yang paling umum.

Dengan PAT, beberapa alamat dapat dipetakan ke satu atau beberapa alamat, karena setiap alamat pribadi juga dilacak oleh nomor port. Saat perangkat memulai sesi TCP/IP, perangkat menghasilkan nilai port sumber TCP atau UDP untuk mengidentifikasi sesi secara unik. Ketika router NAT menerima paket dari klien, ia menggunakan nomor port sumbernya untuk secara unik mengidentifikasi terjemahan NAT tertentu.

PAT memastikan bahwa perangkat menggunakan nomor port TCP yang berbeda untuk setiap sesi dengan server di Internet. Ketika respon datang kembali dari server, nomor port sumber, yang menjadi nomor port tujuan pada perjalanan kembali, menentukan ke perangkat mana router meneruskan paket-paket tersebut. Proses PAT juga memvalidasi bahwa paket masuk telah diminta, sehingga menambah tingkat keamanan pada sesi tersebut.

Animasi menggambarkan proses PAT. PAT menambahkan nomor port sumber unik ke dalam alamat global untuk membedakan terjemahan.

Saat R2 memproses setiap paket, ia menggunakan nomor port (1331 dan 1555, dalam contoh ini) untuk mengidentifikasi perangkat asal paket. Alamat sumber (SA) adalah alamat lokal di dalam dengan nomor port yang ditetapkan TCP/IP ditambahkan. Alamat tujuan (DA) adalah alamat lokal luar dengan nomor port layanan yang ditambahkan. Dalam contoh ini, port layanannya adalah 80: HTTP.

Untuk alamat sumber, R2 menerjemahkan alamat lokal dalam ke alamat global dalam dengan nomor port ditambahkan. Alamat tujuan tidak diubah, namun sekarang disebut sebagai alamat IP global luar. Saat server web membalas, jalurnya terbalik.
