Konfigurasi NAT

Penerusan Pelabuhan

Menerapkan penerusan port dengan perintah IOS mirip dengan perintah yang digunakan untuk mengkonfigurasi NAT statis. Penerusan port pada dasarnya adalah terjemahan NAT statis dengan nomor port TCP atau UDP tertentu.

Gambar 1 menunjukkan perintah NAT statis yang digunakan untuk mengkonfigurasi penerusan port menggunakan IOS.

Gambar 2 menunjukkan contoh konfigurasi port forwarding menggunakan perintah IOS pada router R2. 192.168.10.254 adalah alamat IPv4 lokal di dalam server web yang mendengarkan pada port 80. Pengguna akan mengakses server web internal ini menggunakan alamat IP global 209.165.200.225, alamat IPv4 publik yang unik secara global. Dalam hal ini, ini adalah alamat antarmuka Serial 0/1/0 R2. Port global dikonfigurasikan sebagai 8080. Ini akan menjadi port tujuan yang digunakan, bersama dengan alamat IPv4 global 209.165.200.225 untuk mengakses server web internal. Perhatikan dalam konfigurasi NAT, parameter perintah berikut:

  • ip lokal = 192.168.10.254

  • pelabuhan lokal = 80

  • global-ip = 209.165.200.225

  • pelabuhan global = 8080

Ketika nomor port terkenal tidak digunakan, klien harus menentukan nomor port dalam aplikasi.

Seperti jenis NAT lainnya, penerusan port memerlukan konfigurasi antarmuka NAT dalam dan luar.

Mirip dengan NAT statis, itutampilkan terjemahan ip natperintah dapat digunakan untuk memverifikasi penerusan port, seperti yang ditunjukkan pada Gambar 3.

Dalam contoh, ketika router menerima paket dengan alamat IPv4 global dalam 209.165.200.225 dan port tujuan TCP 8080, router melakukan pencarian tabel NAT menggunakan alamat IPv4 tujuan dan port tujuan sebagai kuncinya. Router kemudian menerjemahkan alamat tersebut ke alamat lokal dalam host 192.168.10.254 dan port tujuan 80. R2 kemudian meneruskan paket ke server web. Untuk mengembalikan paket dari server web kembali ke klien, proses ini dibalik.
