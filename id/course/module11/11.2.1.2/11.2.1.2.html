Konfigurasi NAT

Mengonfigurasi NAT Statis

Menggunakan konfigurasi sebelumnya, gambar tersebut mengilustrasikan proses penerjemahan NAT statis antara klien dan server web. Biasanya terjemahan statis digunakan ketika klien di jaringan luar (Internet) perlu menjangkau server di jaringan dalam (internal).

1. Klien ingin membuka koneksi ke web server. Klien mengirimkan paket ke server web menggunakan alamat tujuan IPv4 publik 209.165.201.5. Ini adalah alamat global bagian dalam server web.

2. Paket pertama yang diterima R2 dari klien pada antarmuka luar NAT-nya menyebabkan R2 memeriksa tabel NAT-nya. Alamat IPv4 tujuan terletak di tabel NAT dan diterjemahkan.

3. R2 menggantikan alamat global dalam 209.165.201.5 dengan alamat lokal dalam 192.168.10.254. R2 kemudian meneruskan paket menuju web server.

4. Server web menerima paket dan merespons klien menggunakan alamat lokal di dalam, 192.168.10.254.

5a. R2 menerima paket dari server web pada antarmuka bagian dalam NAT dengan alamat sumber dari alamat lokal bagian dalam server web, 192.168.10.254.

5b. R2 memeriksa tabel NAT untuk terjemahan alamat lokal di dalam. Alamatnya ditemukan di tabel NAT. R2 menerjemahkan alamat sumber ke alamat global dalam 209.165.201.5 dan meneruskan paket keluar dari antarmuka serial 0/1/0 menuju klien.

6. Klien menerima paket dan melanjutkan percakapan. Router NAT melakukan Langkah 2 hingga 5b untuk setiap paket. (Langkah 6 tidak ditampilkan pada gambar.)
