Segmentasi VLAN

VLAN dalam Lingkungan Multi-Switched

Sakelar Catalyst 2960 Series adalah perangkat Lapisan 2. Mereka menggunakan informasi header frame Ethernet untuk meneruskan paket. Mereka tidak memiliki tabel routing. Header frame Ethernet standar tidak berisi informasi tentang VLAN yang memiliki frame tersebut; dengan demikian, ketika frame Ethernet ditempatkan pada trunk, informasi tentang VLAN yang menjadi miliknya harus ditambahkan. Proses ini, yang disebut penandaan, dilakukan dengan menggunakan header IEEE 802.1Q, yang ditentukan dalam standar IEEE 802.1Q. Header 802.1Q menyertakan tag 4-byte yang dimasukkan ke dalam header frame Ethernet asli, yang menentukan VLAN tempat frame tersebut berada.

Ketika switch menerima frame pada port yang dikonfigurasi dalam mode akses dan menetapkan VLAN, switch menyisipkan tag VLAN di header frame, menghitung ulang FCS, dan mengirimkan frame yang diberi tag keluar dari port trunk.

Detail Bidang Tag VLAN

Bidang tag VLAN terdiri dari bidang Tipe, bidang informasi kontrol tag, dan bidang FCS:

  • Jenis- Nilai 2 byte yang disebut nilai tag protokol ID (TPID). Untuk Ethernet, disetel ke heksadesimal 0x8100.

  • Prioritas pengguna- Nilai 3-bit yang mendukung implementasi level atau layanan.

  • Pengidentifikasi Format Kanonik (CFI)- Pengidentifikasi 1-bit yang memungkinkan frame Token Ring dibawa melalui link Ethernet.

  • ID VLAN (VID)- Nomor identifikasi VLAN 12-bit yang mendukung hingga 4096 ID VLAN.

Setelah sakelar menyisipkan bidang informasi kontrol Tipe dan tag, sakelar akan menghitung ulang nilai FCS dan memasukkan FCS baru ke dalam bingkai.
