Penugasan VLAN

Pada gambar tersebut,tidak ada vlanvlan-idperintah mode konfigurasi global digunakan untuk menghapus VLAN 20 dari switch. Switch S1 memiliki konfigurasi minimal dengan semua port di VLAN 1 dan VLAN 20 yang tidak digunakan di database VLAN. Itutampilkan vlan singkatperintah memverifikasi bahwa VLAN 20 tidak lagi ada di file vlan.dat setelah menggunakantidak ada vlan 20memerintah.

Peringatan: Sebelum menghapus VLAN, pastikan untuk menetapkan ulang terlebih dahulu semua port anggota ke VLAN yang berbeda. Port apa pun yang tidak dipindahkan ke VLAN aktif tidak dapat berkomunikasi dengan host lain setelah VLAN dihapus dan hingga port tersebut ditugaskan ke VLAN aktif.

Alternatifnya, seluruh file vlan.dat dapat dihapus menggunakanhapus flash:vlan.datperintah mode EXEC istimewa. Versi perintah yang disingkat (hapus vlan.dat) dapat digunakan jika file vlan.dat belum dipindahkan dari lokasi defaultnya. Setelah mengeluarkan perintah ini dan memuat ulang sakelar, VLAN yang dikonfigurasi sebelumnya tidak lagi ada. Ini secara efektif menempatkan saklar ke kondisi default pabrik mengenai konfigurasi VLAN.

Catatan: Untuk saklar Katalis,hapus startup-configperintah harus menyertaihapus vlan.datperintah sebelum memuat ulang untuk mengembalikan sakelar ke kondisi default pabrik.
