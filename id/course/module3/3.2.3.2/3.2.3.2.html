Protokol Trunking Dinamis

Antarmuka Ethernet pada switch Catalyst 2960 dan Catalyst 3560 Series mendukung mode trunking yang berbeda dengan bantuan DTP:

  • akses mode switchport - Menempatkan antarmuka (port akses) ke mode non-batang permanen dan bernegosiasi untuk mengubah tautan menjadi tautan non-batang. Antarmuka menjadi antarmuka non-batang, terlepas dari apakah antarmuka tetangganya merupakan antarmuka trunk.

  • mode switchport otomatis dinamis - Membuat antarmuka dapat mengubah tautan menjadi tautan utama. Antarmuka menjadi antarmuka trunk jika antarmuka tetangga diatur ke mode trunk atau yang diinginkan. Mode switchport default untuk semua antarmuka Ethernet adalahotomatis dinamis.

  • mode switchport dinamis diinginkan - Membuat antarmuka secara aktif berupaya mengubah tautan menjadi tautan utama. Antarmuka menjadi antarmuka trunk jika antarmuka tetangga diatur ke mode trunk, diinginkan, atau otomatis. Ini adalah mode switchport default pada switch lama, seperti switch Catalyst 2950 dan 3550 Series.

  • bagasi mode switchport - Menempatkan antarmuka ke mode trunking permanen dan bernegosiasi untuk mengubah link tetangga menjadi link trunk. Antarmuka menjadi antarmuka trunk meskipun antarmuka tetangganya bukan antarmuka trunk.

  • switchport tidak bernegosiasi - Mencegah antarmuka menghasilkan bingkai DTP. Anda dapat menggunakan perintah ini hanya ketika mode switchport antarmuka aktifmengaksesorbelalai. Anda harus mengkonfigurasi antarmuka tetangga secara manual sebagai antarmuka trunk untuk membuat link trunk.
