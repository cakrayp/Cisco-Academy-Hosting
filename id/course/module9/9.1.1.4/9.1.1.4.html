Tujuan ACL

Contoh Penyaringan Paket

Untuk memahami konsep bagaimana router menggunakan packet filtering, bayangkan seorang penjaga ditempatkan di pintu yang terkunci. Instruksi penjaga adalah hanya mengizinkan orang-orang yang namanya tercantum dalam daftar untuk melewati pintu. Penjaga menyaring orang berdasarkan kriteria agar nama mereka ada dalam daftar resmi. ACL bekerja dengan cara yang sama, membuat keputusan berdasarkan kriteria yang ditetapkan.

Misalnya, ACL dapat dikonfigurasi secara logis, "Izinkan akses web ke pengguna dari jaringan A tetapi tolak semua layanan lain untuk pengguna jaringan A. Tolak akses HTTP ke pengguna dari jaringan B, tetapi izinkan pengguna jaringan B memiliki semua akses lainnya." Lihat gambar untuk memeriksa jalur keputusan yang digunakan filter paket untuk menyelesaikan tugas ini.

Untuk skenario ini, filter paket melihat setiap paket sebagai berikut:

  • Jika paket tersebut adalah TCP SYN dari Jaringan A menggunakan Port 80, maka diperbolehkan untuk lewat. Semua akses lainnya ditolak untuk pengguna tersebut.

  • Jika paket tersebut adalah TCP SYN dari Jaringan B yang menggunakan Port 80, maka paket tersebut diblokir. Namun, semua akses lainnya diizinkan.

Ini hanyalah contoh sederhana. Beberapa aturan dapat dikonfigurasi untuk mengizinkan atau menolak layanan lebih lanjut kepada pengguna tertentu.
