FTP Ditolak

Skenario

Baru-baru ini dilaporkan bahwa virus sedang meningkat dalam jaringan bisnis kecil dan menengah Anda. Administrator jaringan Anda telah melacak kinerja jaringan dan menentukan bahwa satu host tertentu terus-menerus mengunduh file dari server FTP jarak jauh. Host ini mungkin saja merupakan sumber virus yang menyebar ke seluruh jaringan!

Gunakan Packet Tracer untuk menyelesaikan aktivitas ini. Tulis ACL bernama untuk menolak akses host ke server FTP. Terapkan ACL ke antarmuka paling efektif di router.

Untuk melengkapi topologi fisik, Anda harus menggunakan:

  • Satu stasiun host PC

  • Dua saklar

  • Satu Router Layanan Terintegrasi seri Cisco 1941

  • Satu pelayan

Menggunakan alat teks Packet Tracer, catat ACL yang Anda siapkan. Validasi bahwa ACL berfungsi untuk menolak akses ke server FTP dengan mencoba mengakses alamat server FTP. Amati apa yang terjadi saat dalam mode simulasi.

Simpan file Anda dan bersiaplah untuk membaginya dengan siswa lain, atau dengan seluruh kelas.
