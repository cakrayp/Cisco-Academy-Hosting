Operasi IP ACL

Tujuan ACL

Jadi bagaimana ACL menggunakan informasi yang dikirimkan selama percakapan TCP/IP untuk memfilter lalu lintas?

Pemfilteran paket, terkadang disebut pemfilteran paket statis, mengontrol akses ke jaringan dengan menganalisis paket masuk dan keluar dan meneruskan atau membuangnya berdasarkan kriteria tertentu, seperti alamat IP sumber, alamat IP tujuan, dan protokol yang dibawa dalam paket.

Router bertindak sebagai filter paket ketika meneruskan atau menolak paket sesuai dengan aturan penyaringan. Ketika sebuah paket tiba di router pemfilteran paket, router mengekstrak informasi tertentu dari header paket. Dengan menggunakan informasi ini, router membuat keputusan, berdasarkan aturan filter yang dikonfigurasi, apakah paket dapat melewati atau dibuang. Seperti yang ditunjukkan pada gambar, pemfilteran paket dapat bekerja pada lapisan model OSI yang berbeda, atau pada lapisan internet TCP/IP.

Router pemfilteran paket menggunakan aturan untuk menentukan apakah akan mengizinkan atau menolak lalu lintas. Router juga dapat melakukan pemfilteran paket pada Layer 4, lapisan transport. Router dapat memfilter paket berdasarkan port sumber dan port tujuan segmen TCP atau UDP. Aturan-aturan ini didefinisikan menggunakan ACL.

ACL adalah daftar berurutan pernyataan izin atau penolakan, yang dikenal sebagai entri kontrol akses (ACE). ACE juga biasa disebut pernyataan ACL. ACE dapat dibuat untuk memfilter lalu lintas berdasarkan kriteria tertentu seperti: alamat sumber, alamat tujuan, protokol, dan nomor port. Ketika lalu lintas jaringan melewati antarmuka yang dikonfigurasi dengan ACL, router membandingkan informasi di dalam paket dengan masing-masing ACE, secara berurutan, untuk menentukan apakah paket tersebut cocok dengan salah satu pernyataan. Jika ditemukan kecocokan, paket akan diproses sesuai dengan itu. Dengan cara ini, ACL dapat dikonfigurasi untuk mengontrol akses ke jaringan atau subnet.

Untuk mengevaluasi lalu lintas jaringan, ACL mengekstrak informasi berikut dari header paket Layer 3:

  • Alamat IP sumber

  • Alamat IP tujuan

  • Jenis pesan ICMP

ACL juga dapat mengekstrak informasi lapisan atas dari header Layer 4, termasuk:

  • Port sumber TCP/UDP

  • Port tujuan TCP/UDP
