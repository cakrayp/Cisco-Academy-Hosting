Switch Keamanan: Manajemen dan Implementasi

Akses Jarak Jauh yang Aman

Sebelum mengonfigurasi SSH, sakelar harus dikonfigurasi minimal dengan nama host unik dan pengaturan konektivitas jaringan yang benar.

Langkah 1. Verifikasi dukungan SSH.

Gunakantunjukkan ip sshperintah untuk memverifikasi bahwa sakelar mendukung SSH. Jika switch tidak menjalankan IOS yang mendukung fitur kriptografi, perintah ini tidak dikenali.

Langkah 2. Konfigurasikan domain IP.

Konfigurasikan nama domain IP jaringan menggunakanip nama domainnama domainperintah mode konfigurasi global. Pada Gambar 1,nama domainnilai adalah cisco.com.

Langkah 3. Hasilkan pasangan kunci RSA.

Menghasilkan pasangan kunci RSA secara otomatis mengaktifkan SSH. Gunakankunci kripto menghasilkan rsaperintah mode konfigurasi global untuk mengaktifkan server SSH di sakelar dan menghasilkan pasangan kunci RSA. Saat membuat kunci RSA, administrator diminta memasukkan panjang modulus. Cisco merekomendasikan ukuran modulus minimum 1.024 bit (lihat contoh konfigurasi pada Gambar 1). Panjang modulus yang lebih panjang lebih aman, namun memerlukan waktu lebih lama untuk dibuat dan digunakan.

Catatan: Untuk menghapus pasangan kunci RSA, gunakankunci kripto memusatkan perhatian pada rsaperintah mode konfigurasi global. Setelah pasangan kunci RSA dihapus, server SSH otomatis dinonaktifkan.

Langkah 4. Konfigurasikan otentikasi pengguna.

Server SSH dapat mengautentikasi pengguna secara lokal atau menggunakan server autentikasi. Untuk menggunakan metode otentikasi lokal, buat pasangan nama pengguna dan kata sandi menggunakannama belakangnama belakangkata sandikata sandiperintah mode konfigurasi global. Misalnya saja penggunaadmindiberi kata sandiccna.

Langkah 5. Konfigurasikan garis vty.

Aktifkan protokol SSH pada baris vty menggunakanmasukan transportasi sshperintah mode konfigurasi baris. Catalyst 2960 memiliki garis vty mulai dari 0 hingga 15. Konfigurasi ini mencegah koneksi non-SSH (seperti Telnet) dan membatasi switch untuk hanya menerima koneksi SSH. Gunakanbaris vtyperintah mode konfigurasi global dan kemudianmasuk lokalperintah mode konfigurasi baris untuk memerlukan otentikasi lokal untuk koneksi SSH dari database nama pengguna lokal.

Gunakan Pemeriksa Sintaks pada Gambar 2 untuk mengkonfigurasi SSH pada sakelar S1.
