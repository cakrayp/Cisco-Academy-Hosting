Ringkasan

Saat switch Cisco LAN pertama kali dinyalakan, switch tersebut akan melalui urutan boot berikut:

1. Pertama, saklar memuat program power-on self-test (POST) yang disimpan dalam ROM. POST memeriksa subsistem CPU. Ini menguji CPU, DRAM, dan bagian perangkat flash yang membentuk sistem file flash.

2. Selanjutnya, saklar memuat perangkat lunak boot loader. Boot loader adalah program kecil yang disimpan dalam ROM dan dijalankan segera setelah POST berhasil diselesaikan.

3. Boot loader melakukan inisialisasi CPU tingkat rendah. Ini menginisialisasi register CPU, yang mengontrol di mana memori fisik dipetakan, jumlah memori, dan kecepatannya.

4. Boot loader menginisialisasi sistem file flash pada board sistem.

5. Terakhir, boot loader menemukan dan memuat image perangkat lunak sistem operasi IOS default ke dalam memori dan menyerahkan kendali peralihan ke IOS.

File Cisco IOS spesifik yang dimuat ditentukan oleh variabel lingkungan BOOT. Setelah Cisco IOS dimuat, ia menggunakan perintah yang ditemukan di file startup-config untuk menginisialisasi dan mengkonfigurasi antarmuka. Jika file Cisco IOS hilang atau rusak, program boot loader dapat digunakan untuk memuat ulang atau memulihkan masalah.

Status operasional sakelar ditampilkan melalui serangkaian LED di panel depan. LED ini menampilkan hal-hal seperti status port, dupleks, dan kecepatan.

Alamat IP dikonfigurasi pada SVI VLAN manajemen untuk memungkinkan konfigurasi perangkat jarak jauh. Gateway default milik VLAN manajemen harus dikonfigurasi pada switch menggunakanip gateway defaultmemerintah. Jika gateway default tidak dikonfigurasi dengan benar, manajemen jarak jauh tidak dapat dilakukan. Direkomendasikan agar Secure Shell (SSH) digunakan untuk menyediakan koneksi manajemen yang aman (terenkripsi) ke perangkat jarak jauh untuk mencegah pengendusan nama pengguna dan kata sandi yang tidak terenkripsi yang mungkin terjadi saat menggunakan protokol seperti Telnet.

Salah satu kelebihan switch adalah memungkinkan komunikasi dupleks penuh antar perangkat yang secara efektif menggandakan kecepatan komunikasi. Meskipun dimungkinkan untuk menentukan pengaturan kecepatan dan dupleks dari antarmuka sakelar, disarankan agar sakelar diizinkan untuk menyetel parameter ini secara otomatis untuk menghindari kesalahan.

Keamanan port switch merupakan persyaratan untuk mencegah serangan seperti MAC Address Flooding dan DHCP Spoofing. Port switch harus dikonfigurasi untuk hanya mengizinkan frame dengan alamat MAC sumber tertentu untuk masuk. Frame dari alamat MAC sumber yang tidak diketahui harus ditolak dan menyebabkan port dimatikan untuk mencegah serangan lebih lanjut.

Keamanan port hanyalah salah satu pertahanan terhadap gangguan jaringan. Ada 10 praktik terbaik yang mewakili asuransi terbaik untuk suatu jaringan:

  • Kembangkan kebijakan keamanan tertulis untuk organisasi.

  • Matikan layanan dan port yang tidak digunakan.

  • Gunakan kata sandi yang kuat dan sering-seringlah mengubahnya.

  • Kontrol akses fisik ke perangkat.

  • Hindari penggunaan situs web HTTP standar yang tidak aman, terutama untuk layar login. Sebaliknya gunakan HTTPS yang lebih aman.

  • Lakukan pencadangan dan uji file yang dicadangkan secara rutin.

  • Mendidik karyawan tentang serangan rekayasa sosial, dan mengembangkan kebijakan untuk memvalidasi identitas melalui telepon, email, dan secara langsung.

  • Enkripsi data sensitif dan lindungi dengan kata sandi yang kuat.

  • Menerapkan perangkat keras dan perangkat lunak keamanan, seperti firewall.

  • Selalu perbarui perangkat lunak iOS dengan menginstal patch keamanan setiap minggu atau setiap hari, jika memungkinkan.

Metode-metode ini hanyalah titik awal untuk manajemen keamanan. Organisasi harus tetap waspada setiap saat untuk mempertahankan diri dari ancaman yang terus berkembang.
