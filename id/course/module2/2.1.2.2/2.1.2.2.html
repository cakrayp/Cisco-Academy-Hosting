Konfigurasikan Port Sakelar

Dupleks dan Kecepatan

Port switch dapat dikonfigurasi secara manual dengan pengaturan dupleks dan kecepatan tertentu. Gunakanrangkapperintah mode konfigurasi antarmuka untuk secara manual menentukan mode dupleks untuk port switch. Gunakankecepatanperintah mode konfigurasi antarmuka untuk menentukan kecepatan port switch secara manual. Pada Gambar 1, port F0/1 pada sakelar S1 dan S2 dikonfigurasi secara manual denganpenuhkata kunci untukrangkapperintah, dan 100 kata kunci untukkecepatanmemerintah.

Pengaturan default untuk duplex dan kecepatan untuk port switch pada switch Cisco Catalyst 2960 dan 3560 adalah otomatis. Port 10/100/1000 beroperasi dalam mode setengah atau dupleks penuh bila diatur ke 10 atau 100 Mb/s, namun bila diatur ke 1000 Mb/s (1 Gb/s), port hanya beroperasi dalam mode dupleks penuh. Cisco merekomendasikan hanya menggunakanmobilperintah untuk dupleks dankecepatanperintah untuk menghindari masalah konektivitas antar perangkat. Saat memecahkan masalah port switch, pengaturan dupleks dan kecepatan harus diperiksa.

Catatan: Ketidakcocokan pengaturan mode dupleks dan kecepatan port switch dapat menyebabkan masalah konektivitas. Kegagalan negosiasi otomatis menciptakan pengaturan yang tidak cocok.

Semua port serat optik, seperti port 100BASE-FX, hanya beroperasi pada satu kecepatan preset dan selalu full-duplex.

Gunakan Pemeriksa Sintaks pada Gambar 2 untuk mengkonfigurasi port F0/1 pada sakelar S1.
