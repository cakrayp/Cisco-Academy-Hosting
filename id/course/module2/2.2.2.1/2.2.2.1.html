Switch Keamanan: Manajemen dan Implementasi

Masalah Keamanan di LAN

Keamanan switch dasar tidak menghentikan serangan berbahaya. Keamanan adalah proses berlapis yang pada dasarnya tidak pernah selesai. Semakin sadar tim profesional jaringan dalam suatu organisasi mengenai serangan keamanan dan bahaya yang ditimbulkannya, semakin baik. Beberapa jenis serangan keamanan dijelaskan di sini, namun rincian cara kerja beberapa serangan tersebut berada di luar cakupan kursus ini. Informasi lebih rinci dapat ditemukan di kursus Protokol WAN CCNA dan kursus Keamanan CCNA.

Alamat MAC Banjir

Tabel alamat MAC di switch berisi alamat MAC yang terkait dengan setiap port fisik dan VLAN terkait untuk setiap port. Ketika switch Layer 2 menerima frame, switch mencari alamat MAC tujuan di tabel alamat MAC. Semua model sakelar Catalyst menggunakan tabel alamat MAC untuk peralihan Lapisan 2. Ketika frame tiba di port switch, alamat MAC sumber dicatat dalam tabel alamat MAC. Jika ada entri untuk alamat MAC, switch meneruskan frame ke port yang benar. Jika alamat MAC tidak ada dalam tabel alamat MAC, switch akan membanjiri frame dari setiap port pada switch, kecuali port tempat frame diterima.

Perilaku pembanjiran alamat MAC dari sebuah switch untuk alamat yang tidak diketahui dapat digunakan untuk menyerang sebuah switch. Jenis serangan ini disebut serangan overflow tabel alamat MAC. Serangan luapan tabel alamat MAC kadang-kadang disebut sebagai serangan banjir MAC, dan serangan luapan tabel CAM. Angka-angka tersebut menunjukkan bagaimana jenis serangan ini bekerja.

Pada Gambar 1, host A mengirimkan lalu lintas ke host B. Switch menerima frame dan mencari alamat MAC tujuan di tabel alamat MAC-nya. Jika switch tidak dapat menemukan MAC tujuan dalam tabel alamat MAC, switch kemudian menyalin frame dan membanjiri (menyiarkannya) keluar dari setiap port switch, kecuali port dimana frame tersebut diterima.

Pada Gambar 2, host B menerima frame dan mengirimkan balasan ke host A. Switch kemudian mengetahui bahwa alamat MAC untuk host B terletak di port 2 dan mencatat informasi tersebut ke dalam tabel alamat MAC.

Host C juga menerima frame dari host A ke host B, tetapi karena alamat MAC tujuan frame tersebut adalah host B, host C membuang frame tersebut.

Seperti yang ditunjukkan pada Gambar 3, setiap frame yang dikirim oleh host A (atau host lainnya) ke host B diteruskan ke port 2 switch dan tidak disiarkan ke setiap port.

Tabel alamat MAC terbatas ukurannya. Serangan banjir MAC memanfaatkan batasan ini untuk membanjiri switch dengan alamat MAC sumber palsu hingga tabel alamat MAC switch penuh.

Seperti yang ditunjukkan pada Gambar 4, penyerang di host C dapat mengirim frame dengan alamat MAC sumber dan tujuan palsu yang dibuat secara acak ke switch. Switch memperbarui tabel alamat MAC dengan informasi dalam frame palsu. Ketika tabel alamat MAC penuh dengan alamat MAC palsu, saklar memasuki apa yang dikenal sebagai mode fail-open. Dalam mode ini, saklar menyiarkan semua frame ke semua mesin di jaringan. Hasilnya, penyerang dapat melihat semua frame.

Beberapa alat penyerang jaringan dapat menghasilkan hingga 155.000 entri MAC pada satu saklar per menit. Tergantung pada switch, ukuran tabel alamat MAC maksimum bervariasi.

Seperti ditunjukkan pada Gambar 5, selama tabel alamat MAC pada switch tetap penuh, switch menyiarkan semua frame yang diterima dari setiap port. Dalam contoh ini, frame yang dikirim dari host A ke host B juga disiarkan keluar dari port 3 pada switch dan dilihat oleh penyerang di host C.

Salah satu cara untuk memitigasi serangan table overflow alamat MAC adalah dengan mengkonfigurasi keamanan port.
