Konfigurasi Sakelar Dasar

Konfigurasikan Switch dengan Pengaturan Awal

Setelah switch Cisco dinyalakan, switch tersebut akan melalui urutan booting berikut:

1. Pertama, saklar memuat program power-on self-test (POST) yang disimpan dalam ROM. POST memeriksa subsistem CPU. Ini menguji CPU, DRAM, dan bagian perangkat flash yang membentuk sistem file flash.

2. Selanjutnya, saklar memuat perangkat lunak boot loader. Boot loader adalah program kecil yang disimpan dalam ROM dan dijalankan segera setelah POST berhasil diselesaikan.

3. Boot loader melakukan inisialisasi CPU tingkat rendah. Ini menginisialisasi register CPU, yang mengontrol di mana memori fisik dipetakan, jumlah memori, dan kecepatannya.

4. Boot loader menginisialisasi sistem file flash pada board sistem.

5. Terakhir, boot loader menemukan dan memuat image perangkat lunak sistem operasi IOS default ke dalam memori dan menyerahkan kendali peralihan ke IOS.

Boot loader menemukan image Cisco IOS pada switch sebagai berikut: switch mencoba melakukan booting secara otomatis dengan menggunakan informasi dalam variabel lingkungan BOOT. Jika variabel ini tidak disetel, saklar akan mencoba memuat dan mengeksekusi file pertama yang dapat dieksekusi dengan melakukan pencarian rekursif dan mendalam di seluruh sistem file flash. Dalam pencarian direktori yang mendalam terlebih dahulu, setiap subdirektori yang ditemukan dicari sepenuhnya sebelum melanjutkan pencarian di direktori asli. Pada switch Catalyst 2960 Series, file gambar biasanya terdapat dalam direktori yang memiliki nama yang sama dengan file gambar (tidak termasuk ekstensi file .bin).

Sistem operasi IOS kemudian menginisialisasi antarmuka menggunakan perintah Cisco IOS yang terdapat di file konfigurasi, konfigurasi startup, yang disimpan di NVRAM.

Pada gambar, variabel lingkungan BOOT diatur menggunakansistem bootperintah mode konfigurasi global. Gunakantampilkan bootvarmemerintah (tampilkan bootdi versi IOS yang lebih lama) untuk melihat file boot IOS saat ini disetel ke mana.
