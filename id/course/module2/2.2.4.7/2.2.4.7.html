Switch Keamanan: Manajemen dan Implementasi

Ganti Keamanan Port

Ketika port dikonfigurasi dengan keamanan port, pelanggaran dapat menyebabkan port menjadi error dinonaktifkan. Ketika suatu port dinonaktifkan karena kesalahan, port tersebut akan dimatikan secara efektif dan tidak ada lalu lintas yang dikirim atau diterima pada port tersebut. Serangkaian pesan terkait keamanan port ditampilkan di konsol (Gambar 1).

Catatan: Protokol port dan status tautan diubah menjadi tidak aktif.

LED port akan berubah menjadi oranye. Itutampilkan antarmukaperintah mengidentifikasi status port sebagaierr-dinonaktifkan(Gambar 2). Keluaran daritampilkan antarmuka keamanan portperintah sekarang menunjukkan status port sebagaipenutupan aman. Karena mode pelanggaran keamanan port diatur kepenutupan, port dengan pelanggaran keamanan masuk ke status kesalahan dinonaktifkan.

Administrator harus menentukan penyebab pelanggaran keamanan sebelum mengaktifkan kembali port. Jika perangkat yang tidak sah terhubung ke port aman, port tersebut tidak boleh diaktifkan kembali sampai ancaman keamanan dihilangkan. Untuk mengaktifkan kembali port, gunakanpenutupanperintah mode konfigurasi antarmuka (Gambar 3). Kemudian, gunakantidak ada penutupanperintah konfigurasi antarmuka untuk membuat port beroperasi.
