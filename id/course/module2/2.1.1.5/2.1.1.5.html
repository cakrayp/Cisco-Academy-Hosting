Konfigurasi Sakelar Dasar

Konfigurasikan Switch dengan Pengaturan Awal

Langkah 1. Konfigurasikan Antarmuka Manajemen

Alamat IP dan subnet mask dikonfigurasi pada SVI manajemen peralihan dari mode konfigurasi antarmuka VLAN. Seperti yang ditunjukkan pada Gambar 1,antarmuka vlan 99perintah digunakan untuk masuk ke mode konfigurasi antarmuka. Itualamat IPperintah digunakan untuk mengkonfigurasi alamat IP. Itutidak ada penutupanperintah mengaktifkan antarmuka. Dalam contoh ini, VLAN 99 dikonfigurasi dengan alamat IP 172.17.99.11.

SVI untuk VLAN 99 tidak akan muncul sebagai "up/up" sampai VLAN 99 dibuat dan ada perangkat yang terhubung ke port switch yang terkait dengan VLAN 99. Untuk membuat VLAN dengan vlan_id 99, dan mengaitkannya ke antarmuka, gunakan perintah berikut:

S1(konfigurasi)# vlan vlan_id

S1(config-vlan)# nama vlan_nama

S1(konfigurasi)# akhir

S1(konfigurasi)# antarmuka antarmuka_id

S1(config-jika)# vlan akses switchport vlan_id

Langkah 2. Konfigurasikan Gerbang Default

Switch harus dikonfigurasi dengan gateway default jika akan dikelola dari jarak jauh dari jaringan yang tidak terhubung langsung. Gateway default adalah router yang terhubung dengan switch. Switch akan meneruskan paket IP dengan alamat IP tujuan di luar jaringan lokal ke gateway default. Seperti yang ditunjukkan pada Gambar 2, R1 adalah gateway default untuk S1. Antarmuka pada R1 yang terhubung ke sakelar memiliki alamat IP 172.17.99.1. Alamat ini adalah alamat gateway default untuk S1.

Untuk mengonfigurasi gateway default untuk sakelar, gunakanip gateway defaultmemerintah. Masukkan alamat IP gateway default. Gateway default adalah alamat IP antarmuka router yang terhubung dengan switch. Gunakansalin menjalankan-config startup-configperintah untuk membuat cadangan konfigurasi Anda.

Langkah 3. Verifikasi Konfigurasi

Seperti yang ditunjukkan pada Gambar 3,tampilkan antarmuka ip secara singkatperintah berguna saat menentukan status antarmuka fisik dan virtual. Output yang ditunjukkan pada gambar mengonfirmasi bahwa antarmuka VLAN 99 telah dikonfigurasi dengan alamat IP dan subnet mask, dan port Fast Ethernet F0/18 telah ditetapkan ke antarmuka manajemen VLAN 99. Kedua antarmuka sekarang “naik/naik” dan beroperasi.
