Switch Keamanan: Manajemen dan Implementasi

Masalah Keamanan di LAN

DHCP adalah protokol yang secara otomatis memberikan host alamat IP yang valid dari kumpulan DHCP. DHCP telah digunakan selama TCP/IP menjadi protokol utama yang digunakan dalam industri untuk mengalokasikan alamat IP klien. Dua jenis serangan DHCP dapat dilakukan terhadap jaringan yang diaktifkan: serangan kelaparan DHCP dan spoofing DHCP.

Dalam serangan kelaparan DHCP, penyerang membanjiri server DHCP dengan permintaan DHCP untuk menggunakan semua alamat IP yang tersedia yang dapat dikeluarkan oleh server DHCP. Setelah alamat IP ini dikeluarkan, server tidak dapat mengeluarkan alamat lagi, dan situasi ini menghasilkan serangan penolakan layanan (DoS) karena klien baru tidak dapat memperoleh akses jaringan. Serangan DoS adalah serangan apa pun yang digunakan untuk membebani perangkat dan layanan jaringan tertentu dengan lalu lintas tidak sah, sehingga mencegah lalu lintas sah mencapai sumber daya tersebut.

Dalam serangan spoofing DHCP, penyerang mengkonfigurasi server DHCP palsu di jaringan untuk mengeluarkan alamat DHCP ke klien. Alasan normal serangan ini adalah untuk memaksa klien menggunakan server Domain Name System (DNS) atau Windows Internet Naming Service (WINS) palsu dan membuat klien menggunakan penyerang, atau mesin yang berada di bawah kendali penyerang, sebagai gateway default mereka.

Kelaparan DHCP sering digunakan sebelum serangan spoofing DHCP untuk menolak layanan ke server DHCP yang sah, sehingga lebih mudah untuk memasukkan server DHCP palsu ke dalam jaringan.

Untuk memitigasi serangan DHCP, gunakan fitur pengintaian DHCP dan keamanan port pada switch Cisco Catalyst. Fitur-fitur ini dibahas dalam topik selanjutnya.
