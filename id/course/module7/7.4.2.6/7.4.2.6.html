Pembaruan Link-State

Langkah terakhir dalam proses routing link-state adalah setiap router menggunakan database untuk membangun peta topologi yang lengkap dan menghitung jalur terbaik ke setiap jaringan tujuan.

Pada akhirnya, semua router menerima LSP dari setiap router link-state lainnya di area routing. LSP ini disimpan dalam database link-state.

Contoh pada gambar menampilkan konten database link-state R1.

Sebagai hasil dari proses banjir, R1 telah mempelajari informasi link-state untuk setiap router di area routingnya. Perhatikan bahwa R1 juga menyertakan informasi link-state-nya sendiri dalam database link-state.

Dengan database link-state yang lengkap, R1 kini dapat menggunakan database dan algoritma shortest path first (SPF) untuk menghitung jalur pilihan atau jalur terpendek ke setiap jaringan sehingga menghasilkan pohon SPF.
