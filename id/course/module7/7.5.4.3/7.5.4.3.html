Analisis Tabel Perutean IPv6

Gambar 1 menyoroti entri tabel routing untuk tiga jaringan jarak jauh (yaitu, R2 LAN, R3 LAN, dan link antara R2 dan R3). Ketiga entri tersebut ditambahkan oleh EIGRP.

Gambar 2 menampilkan entri tabel routing pada R1 untuk rute ke jaringan jarak jauh 2001:DB8:CAFE:3::/64 pada R3. Entri tersebut mengidentifikasi informasi berikut:

  • Sumber rute- Mengidentifikasi bagaimana rute itu dipelajari. Kode umum termasuk O (OSPF), D (EIGRP), R (RIP), dan S (Rute statis).

  • Jaringan tujuan- Mengidentifikasi alamat jaringan IPv6 jarak jauh.

  • Jarak administratif- Mengidentifikasi seberapa dapat dipercayanya sumber rute. IPv6 menggunakan jarak yang sama dengan IPv4.

  • Metrik- Mengidentifikasi nilai yang ditetapkan untuk menjangkau jaringan jarak jauh. Nilai yang lebih rendah menunjukkan rute pilihan.

  • Lompatan berikutnya- Mengidentifikasi alamat IPv6 dari router berikutnya untuk meneruskan paket.

  • Antarmuka keluar- Mengidentifikasi antarmuka keluar yang digunakan untuk meneruskan paket menuju tujuan akhir.

Ketika paket IPv6 tiba di antarmuka router, router memeriksa header IPv6 dan mengidentifikasi alamat IPv6 tujuan. Router kemudian melanjutkan melalui proses pencarian router berikut.

Router memeriksa rute jaringan level 1 untuk mendapatkan kecocokan terbaik dengan alamat tujuan paket IPv6. Sama seperti IPv4, kecocokan terlama adalah kecocokan terbaik. Misalnya, jika ada beberapa kecocokan dalam tabel routing, router akan memilih rute dengan kecocokan terpanjang. Pencocokan dilakukan dengan mencocokkan bit paling kiri dari alamat IPv6 tujuan paket dengan awalan IPv6 dan panjang awalan di tabel perutean IPv6.
