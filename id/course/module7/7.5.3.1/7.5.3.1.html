Proses Pencarian Rute IPv4

Ketika sebuah paket tiba di antarmuka router, router memeriksa header IPv4, mengidentifikasi alamat IPv4 tujuan, dan melanjutkan proses pencarian router.

Pada Gambar 1, router memeriksa rute jaringan level 1 untuk mendapatkan kecocokan terbaik dengan alamat tujuan paket IPv4.

1. Jika yang paling cocok adalah rute pamungkas level 1, maka rute ini digunakan untuk meneruskan paket.

2. Jika yang paling cocok adalah rute induk level 1, lanjutkan ke langkah berikutnya.

Pada Gambar 2, router memeriksa rute anak (rute subnet) dari rute induk untuk mendapatkan kecocokan terbaik.

3. Jika ada kecocokan dengan rute anak level 2, subnet tersebut digunakan untuk meneruskan paket.

4. Jika tidak ada kecocokan dengan salah satu rute anak level 2, lanjutkan ke langkah berikutnya.

Pada Gambar 3, router terus mencari rute supernet level 1 di tabel perutean untuk mencari kecocokan, termasuk rute default, jika ada.

5. Jika sekarang terdapat kecocokan yang lebih rendah dengan supernet level 1 atau rute default, router akan menggunakan rute tersebut untuk meneruskan paket.

6. Jika tidak ada kecocokan dengan rute mana pun di tabel routing, router akan membuang paket tersebut.

Catatan: Rute yang hanya mereferensikan alamat IP hop berikutnya dan bukan antarmuka keluar harus diselesaikan ke rute dengan antarmuka keluar. Pencarian rekursif dilakukan pada alamat IP hop berikutnya hingga rute diselesaikan ke antarmuka keluar.
