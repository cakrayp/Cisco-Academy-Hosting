Perutean RIP dan RIPng

Konfigurasi Protokol RIPng

Seperti halnya IPv4, RIPng jarang digunakan di jaringan modern. Hal ini juga berguna sebagai landasan untuk memahami perutean jaringan dasar. Oleh karena itu, bagian ini memberikan gambaran singkat tentang cara mengkonfigurasi RIPng dasar.

Lihat topologi referensi pada gambar. Dalam skenario ini, semua router telah dikonfigurasi dengan fitur manajemen dasar dan semua antarmuka yang diidentifikasi dalam topologi referensi dikonfigurasi dan diaktifkan. Tidak ada rute statis yang dikonfigurasi dan tidak ada protokol perutean yang diaktifkan; oleh karena itu, akses jaringan jarak jauh saat ini tidak mungkin dilakukan.

Untuk mengaktifkan router IPv6 untuk meneruskan paket IPv6,perutean unicast ipv6harus dikonfigurasi.

Berbeda dengan RIPv2, RIPng diaktifkan pada antarmuka dan bukan pada mode konfigurasi router. Faktanya, tidak adajaringanalamat jaringanperintah tersedia di RIPng. Sebagai gantinya, gunakanrobekan ipv6nama domainmemungkinkanperintah konfigurasi antarmuka.

Pada Gambar 1, perutean unicast IPv6 diaktifkan dan antarmuka Gigabit Ethernet 0/0 dan Serial 0/0/0 diaktifkan untuk RIPng menggunakan nama domain RIP-AS.

Gunakan Pemeriksa Sintaks pada Gambar 2 untuk mengonfigurasi konfigurasi serupa pada R2 dan R3.

Proses untuk menyebarkan rute default di RIPng identik dengan RIPv2 kecuali rute statis default IPv6 harus ditentukan. Misalnya, asumsikan bahwa R1 memiliki koneksi Internet dari antarmuka Serial 0/0/1 ke alamat IP 2001:DB8:FEED:1::1/64. Untuk menyebarkan rute default, R3 harus dikonfigurasi dengan:

  • Rute statis default menggunakanrute ipv6 0::/0 2001:DB8:FEED:1::1perintah konfigurasi global.

  • Iturobekan ipv6nama domaininformasi default berasalperintah mode konfigurasi antarmuka. Ini menginstruksikan R3 untuk menjadi sumber informasi rute default dan menyebarkan rute statis default dalam pembaruan RIPng yang dikirim dari antarmuka yang dikonfigurasi.
