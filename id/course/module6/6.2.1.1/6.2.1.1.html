Konfigurasikan Rute Statis dan Default

Konfigurasikan Rute Statis IPv4

Rute statis dikonfigurasi menggunakanrute ipperintah konfigurasi global. Sintaks perintahnya adalah:

Router(konfigurasi)# rute ip subnet-mask alamat jaringan { alamat ip | nomor antarmuka tipe antarmuka [ alamat ip ]} [ jarak ] [ nama nama ] [ permanen ] [ menandai menandai ]

Parameter berikut diperlukan untuk mengonfigurasi perutean statis:

  • alamat jaringan - Alamat jaringan tujuan dari jaringan jarak jauh yang akan ditambahkan ke tabel perutean, sering kali disebut sebagai awalan.

  • subnet-mask - Subnet mask, atau hanya mask, dari jaringan jarak jauh yang akan ditambahkan ke tabel routing. Subnet mask dapat dimodifikasi untuk meringkas sekelompok jaringan.

Salah satu atau kedua parameter berikut juga harus digunakan:

  • alamat ip - Alamat IP router penghubung yang digunakan untuk meneruskan paket ke jaringan tujuan jarak jauh. Biasa disebut dengan hop berikutnya.

  • keluar-intf - Antarmuka keluar yang digunakan untuk meneruskan paket ke hop berikutnya.

Seperti terlihat pada gambar, sintaks perintah yang umum digunakan adalahrute ipsubnet-mask alamat jaringan{alamat ip|keluar-intf}.

Itujarakparameter digunakan untuk membuat rute statis mengambang dengan mengatur jarak administratif yang lebih tinggi dari rute yang dipelajari secara dinamis.

Catatan: Parameter lainnya tidak relevan untuk bab ini atau untuk studi CCNA.
