Konfigurasikan Rute Statis dan Default

Konfigurasikan Rute Default IPv4

Rute default adalah rute statis yang cocok dengan semua paket. Daripada menyimpan semua rute ke semua jaringan dalam tabel routing, router dapat menyimpan satu rute default untuk mewakili jaringan apa pun yang tidak ada dalam tabel routing.

Router biasanya menggunakan rute default yang dikonfigurasi secara lokal atau dipelajari dari router lain, menggunakan protokol routing dinamis. Rute default digunakan ketika tidak ada rute lain dalam tabel perutean yang cocok dengan alamat IP tujuan paket. Dengan kata lain, jika tidak ada kecocokan yang lebih spesifik, maka rute default digunakan sebagai Gerbang Pilihan Terakhir.

Rute statis default biasanya digunakan saat menghubungkan:

  • Router tepi ke jaringan penyedia layanan

  • Router stub (router dengan hanya satu router tetangga hulu)

Seperti yang ditunjukkan pada gambar, sintaks perintah untuk rute statis default mirip dengan rute statis lainnya, kecuali alamat jaringannya adalah 0.0.0.0 dan subnet masknya adalah 0.0.0.0. Sintaks perintah dasar dari rute statis default adalah:

  • rute ip 0.0.0.0 0.0.0.0 { alamat ip | keluar-intf }

Catatan: Rute statis default IPv4 biasanya disebut sebagai rute quad-zero.
