Konfigurasikan Rute Statis dan Default

Konfigurasikan Rute Statis IPv6

Rute statis untuk IPv6 dikonfigurasi menggunakanrute ipv6perintah konfigurasi global. Gambar 1 menunjukkan versi sederhana dari sintaks perintah:

Router(konfigurasi)# rute ipv6 ipv6-prefix/prefix-length { alamat ipv6 | keluar-intf }

Sebagian besar parameter identik dengan perintah versi IPv4. Rute statis IPv6 juga dapat diimplementasikan sebagai:

  • Rute statis IPv6 standar

  • Rute statis IPv6 default

  • Ringkasan rute statis IPv6

  • Rute statis IPv6 mengambang

Seperti halnya IPv4, rute ini dapat dikonfigurasi sebagai rekursif, terhubung langsung, atau ditentukan sepenuhnya.

Ituperutean unicast ipv6perintah konfigurasi global harus dikonfigurasi agar router dapat meneruskan paket IPv6. Gambar 2 menampilkan pengaktifan perutean unicast IPv6.

Gunakan Pemeriksa Sintaks pada Gambar 3 dan 4 untuk mengaktifkan perutean unicast IPv6 pada R2 dan R3.
