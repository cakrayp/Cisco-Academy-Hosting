Pesan untuk Siswa

Selamat datang di kursus Esensi Perutean dan Peralihan CCNA. Tujuan kursus ini adalah untuk memperkenalkan Anda pada konsep dan teknologi jaringan dasar. Materi kursus online ini akan membantu Anda mengembangkan keterampilan yang diperlukan untuk merencanakan dan mengimplementasikan jaringan kecil di berbagai aplikasi. Keterampilan khusus yang dibahas dalam setiap bab dijelaskan di awal setiap bab.

Anda dapat menggunakan ponsel pintar, tablet, laptop, atau desktop untuk mengakses kursus Anda, berpartisipasi dalam diskusi dengan instruktur Anda, melihat nilai Anda, membaca atau mengulas teks, dan berlatih menggunakan media interaktif. Namun, beberapa media bersifat kompleks dan harus dilihat di PC, begitu pula aktivitas Packet Tracer, kuis, dan ujian.
