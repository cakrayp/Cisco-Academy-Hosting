Protokol Konfigurasi Host Dinamis v6

Pecahkan masalah DHCPv6

Konfigurasi router untuk layanan DHCPv6 stateless dan stateful memiliki banyak kesamaan tetapi juga mencakup perbedaan yang signifikan. Gambar 1 menunjukkan perintah konfigurasi untuk kedua jenis layanan DHCPv6.

DHCPv6 berstatus

Router yang dikonfigurasi untuk layanan DHCPv6 stateful memilikiawalan alamatperintah untuk memberikan informasi pengalamatan.

Untuk layanan DHCPv6 statefulipv6 dan bendera konfigurasi terkelolaperintah mode konfigurasi antarmuka digunakan. Dalam hal ini, klien mengabaikan informasi pengalamatan dalam pesan RA dan berkomunikasi dengan server DHCPv6 untuk pengalamatan dan informasi lainnya.

DHCPv6 tanpa kewarganegaraan

Untuk layanan DHCPv6 tanpa kewarganegaraan,ipv6 dan bendera konfigurasi lainnyaperintah mode konfigurasi antarmuka digunakan. Ini memberi tahu perangkat untuk menggunakan SLAAC untuk menangani informasi dan server DHCPv6 stateless untuk parameter konfigurasi lainnya.

Itutampilkan antarmuka ipv6perintah dapat digunakan untuk melihat konfigurasi saat ini untuk metode alokasi. Seperti yang ditunjukkan pada Gambar 2, baris terakhir dari output menunjukkan bagaimana klien memperoleh alamat dan parameter lainnya.
