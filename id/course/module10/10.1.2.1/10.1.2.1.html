Protokol Konfigurasi Host Dinamis v4

Mengonfigurasi Server DHCPv4 Dasar

Router Cisco yang menjalankan perangkat lunak Cisco IOS dapat dikonfigurasi untuk bertindak sebagai server DHCPv4. Server Cisco IOS DHCPv4 menetapkan dan mengelola alamat IPv4 dari kumpulan alamat tertentu dalam router ke klien DHCPv4. Topologi yang ditunjukkan pada Gambar 1 digunakan untuk mengilustrasikan fungsi ini.

Langkah 1. Tidak termasuk Alamat IPv4

Router yang berfungsi sebagai server DHCPv4 menetapkan semua alamat IPv4 di kumpulan alamat DHCPv4 kecuali dikonfigurasi untuk mengecualikan alamat tertentu. Biasanya, beberapa alamat IPv4 dalam kumpulan ditetapkan ke perangkat jaringan yang memerlukan penetapan alamat statis. Oleh karena itu, alamat IPv4 ini tidak boleh ditetapkan ke perangkat lain. Untuk mengecualikan alamat tertentu, gunakanip dhcp alamat yang dikecualikanperintah seperti yang ditunjukkan pada Gambar 2.

Sebuah alamat tunggal atau serangkaian alamat dapat dikecualikan dengan menentukan alamat rendah dan alamat tinggi dari rentang tersebut. Alamat yang dikecualikan harus mencakup alamat yang ditetapkan ke router, server, printer, dan perangkat lain yang telah dikonfigurasi secara manual.

Langkah 2. Mengonfigurasi Kumpulan DHCPv4

Mengonfigurasi server DHCPv4 melibatkan penentuan kumpulan alamat yang akan ditetapkan. Seperti yang ditunjukkan pada Gambar 3,ip dhcp poolnama kolamperintah membuat kumpulan dengan nama yang ditentukan dan menempatkan router dalam mode konfigurasi DHCPv4, yang diidentifikasi oleh prompt iniRouter(dhcp-config)#.

Langkah 3. Mengonfigurasi Tugas Tertentu

Gambar 4 mencantumkan tugas untuk menyelesaikan konfigurasi kumpulan DHCPv4. Beberapa di antaranya bersifat opsional, sementara yang lainnya harus dikonfigurasi.

Kumpulan alamat dan router gateway default harus dikonfigurasi. Gunakanjaringanpernyataan untuk menentukan kisaran alamat yang tersedia.

Gunakanrouter defaultperintah untuk menentukan router gateway default. Biasanya, gateway adalah antarmuka LAN dari router yang paling dekat dengan perangkat klien. Diperlukan satu gateway, namun Anda dapat mencantumkan hingga delapan alamat jika terdapat beberapa gateway.

Perintah kumpulan DHCPv4 lainnya bersifat opsional. Misalnya, alamat IPv4 server DNS yang tersedia untuk klien DHCPv4 dikonfigurasi menggunakanserver dnsmemerintah. Itunama domaindomainperintah digunakan untuk mendefinisikan nama domain. Durasi sewa DHCPv4 dapat diubah menggunakansewamemerintah. Nilai sewa default adalah satu hari. Itunetbios-nama-serverperintah digunakan untuk mendefinisikan server NetBIOS WINS.

Contoh DHCPv4

Contoh konfigurasi dengan parameter dasar DHCPv4 yang dikonfigurasi pada router R1, server DHCPv4 untuk LAN 192.168.10.0/24 ditunjukkan pada Gambar 5 menggunakan contoh topologi dari Gambar 1.

Menonaktifkan DHCPv4

Layanan DHCPv4 diaktifkan, secara default, pada versi perangkat lunak Cisco IOS yang mendukungnya. Untuk menonaktifkan layanan, gunakantidak ada layanan dhcpperintah mode konfigurasi global. Gunakanlayanan dhcpperintah mode konfigurasi global untuk mengaktifkan kembali proses server DHCPv4. Mengaktifkan layanan tidak berpengaruh jika parameter tidak dikonfigurasi.

Menggunakan aktivitas Pemeriksa Sintaks pada Gambar 6 untuk mengonfigurasi parameter DHCPv4 serupa di R1 untuk LAN 192.168.11.0/24.
