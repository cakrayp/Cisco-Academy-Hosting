Konfigurasikan Klien DHCPv4

Server DHCP khusus dapat diskalakan dan relatif mudah dikelola, namun memerlukan biaya yang mahal untuk memilikinya di setiap lokasi dalam jaringan. Namun, router Cisco dapat dikonfigurasi untuk menyediakan layanan DHCP tanpa memerlukan server khusus. Router Cisco menggunakan rangkaian fitur Cisco IOS, Easy IP, sebagai server DHCP opsional dan berfitur lengkap. Konfigurasi sewa IP mudah selama 24 jam secara default. Sebagai teknisi jaringan untuk perusahaan Anda, Anda ditugaskan untuk mengkonfigurasi router Cisco sebagai server DHCP untuk menyediakan alokasi alamat dinamis kepada klien di jaringan. Anda juga diharuskan untuk mengkonfigurasi router edge sebagai klien DHCP sehingga menerima alamat IP dari jaringan ISP.
