Protokol Konfigurasi Host Dinamis v6

Server DHCPv6 berstatus

Mengonfigurasi server DHCPv6 stateful mirip dengan mengkonfigurasi server stateless. Perbedaan paling signifikan adalah server stateful juga menyertakan informasi pengalamatan IPv6 yang mirip dengan server DHCPv4.

Langkah 1. Aktifkan Perutean IPv6

Seperti yang ditunjukkan pada gambar, gunakanperutean unicast ipv6perintah diperlukan untuk mengaktifkan perutean IPv6. Perintah ini tidak diperlukan agar router menjadi server DHCPv6 stateful, tetapi diperlukan untuk mengirim pesan ICMPv6 RA.

Langkah 2. Konfigurasikan Kumpulan DHCPv6

Itukumpulan dhcp ipv6nama kolamperintah membuat kumpulan dan memasuki router dalam mode konfigurasi DHCPv6, yang diidentifikasi olehRouter(config-dhcpv6)#mengingatkan.

Langkah 3. Konfigurasikan Parameter Kumpulan

Dengan DHCPv6 stateful, semua pengalamatan dan parameter konfigurasi lainnya harus ditetapkan oleh server DHCPv6. Itualamatprefix/length perintah digunakan untuk menunjukkan kumpulan alamat yang akan dialokasikan oleh server. Ituseumur hidupopsi menunjukkan waktu sewa yang valid dan diinginkan dalam hitungan detik. Seperti DHCPv6 stateless, klien menggunakan alamat IPv6 sumber dari paket yang berisi pesan RA.

Informasi lain yang disediakan oleh server DHCPv6 stateful biasanya mencakup alamat server DNS dan nama domain.

Langkah 4. Perintah Antarmuka

Ituserver dhcp ipv6nama kolamperintah antarmuka mengikat kumpulan DHCPv6 ke antarmuka. Router merespons permintaan DHCPv6 stateless pada antarmuka ini dengan informasi yang terdapat dalam kumpulan. Bendera M perlu diubah dari 0 menjadi 1 menggunakan perintah antarmukaipv6 dan bendera konfigurasi terkelola. Ini memberi tahu perangkat untuk tidak menggunakan SLAAC tetapi untuk mendapatkan alamat IPv6 dan semua parameter konfigurasi dari server DHCPv6 stateful.

Contoh Server Stateful DHCPv6

Gambar 2 menunjukkan contoh perintah server DHCPv6 stateful untuk router yang dikonfigurasi pada R1. Perhatikan bahwa gateway default tidak ditentukan karena router secara otomatis akan mengirimkan alamat link-lokalnya sendiri sebagai gateway default. Router R3 dikonfigurasi sebagai klien untuk membantu memverifikasi operasi DHCPv6 stateful.
