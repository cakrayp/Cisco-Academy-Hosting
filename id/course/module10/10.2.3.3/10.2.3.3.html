Server DHCPv6 berstatus

Memverifikasi Server DHCPv6 Stateful

Pada Gambar 1,tampilkan kumpulan dhcp ipv6perintah memverifikasi nama kumpulan DHCPv6 dan parameternya. Jumlah klien aktif adalah 1, yang mencerminkan klien R3 menerima alamat unicast global IPv6 dari server ini.

Itutampilkan pengikatan ipv6 dhcpperintah, seperti yang ditunjukkan pada Gambar 2, menampilkan pengikatan otomatis antara alamat link-lokal klien dan alamat yang diberikan oleh server. FE80::32F7:DFF:FE25:2DE1 adalah alamat link-lokal klien. Dalam contoh ini, ini adalah antarmuka G0/1 dari R3. Alamat ini terikat ke alamat unicast global IPv6, 2001:DB8:CAFE:1:5844:47B2:2603:C171, yang ditetapkan oleh R1, server DHCPv6. Informasi ini dikelola oleh server DHCPv6 stateful dan bukan oleh server DHCPv6 stateless.

Memverifikasi Klien DHCPv6 Stateful

Keluaran daritampilkan antarmuka ipv6perintah yang ditunjukkan pada Gambar 3 memverifikasi alamat unicast global IPv6 pada klien DHCPv6 R3 yang ditetapkan oleh server DHCPv6. Informasi router default bukan dari server DHCPv6, tetapi ditentukan dengan menggunakan alamat IPv6 sumber dari pesan RA. Meskipun klien tidak menggunakan informasi yang terdapat dalam pesan RA, klien dapat menggunakan alamat IPv6 sumber untuk informasi gateway defaultnya.

Gunakan Pemeriksa Sintaks pada Gambar 4 untuk mengonfigurasi dan memverifikasi DHCPv6 stateless.
