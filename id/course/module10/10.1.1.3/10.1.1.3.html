Protokol Konfigurasi Host Dinamis v4

Operasi DHCPv4

Format pesan DHCPv4 digunakan untuk semua transaksi DHCPv4. Pesan DHCPv4 dienkapsulasi dalam protokol transport UDP. Pesan DHCPv4 yang dikirim dari klien menggunakan port sumber UDP 68 dan port tujuan 67. Pesan DHCPv4 yang dikirim dari server ke klien menggunakan port sumber UDP 67 dan port tujuan 68.

Gambar tersebut menunjukkan format pesan DHCPv4. Bidangnya adalah sebagai berikut:

  • Kode Operasi (OP) -Menentukan jenis pesan umum. Nilai 1 menunjukkan pesan permintaan; nilai 2 adalah pesan balasan.

  • Jenis Perangkat Keras- Mengidentifikasi jenis perangkat keras yang digunakan dalam jaringan. Misalnya, 1 adalah Ethernet, 15 adalah Frame Relay, dan 20 adalah jalur serial. Ini adalah kode yang sama yang digunakan dalam pesan ARP.

  • Panjang Alamat Perangkat Keras- Menentukan panjang alamat.

  • melompat- Mengontrol penerusan pesan. Diatur ke 0 oleh klien sebelum mengirimkan permintaan.

  • Pengidentifikasi Transaksi- Digunakan oleh klien untuk mencocokkan permintaan dengan balasan yang diterima dari server DHCPv4.

  • Detik- Mengidentifikasi jumlah detik yang berlalu sejak klien mulai mencoba memperoleh atau memperbarui sewa. Digunakan oleh server DHCPv4 untuk memprioritaskan balasan ketika beberapa permintaan klien belum diselesaikan.

  • Bendera- Digunakan oleh klien yang tidak mengetahui alamat IPv4-nya saat mengirimkan permintaan. Hanya satu dari 16 bit yang digunakan, yaitu flag siaran. Nilai 1 pada kolom ini memberitahu server DHCPv4 atau agen relai yang menerima permintaan bahwa balasan harus dikirim sebagai siaran.

  • Alamat IP Klien- Digunakan oleh klien selama perpanjangan sewa ketika alamat klien valid dan dapat digunakan, bukan selama proses perolehan alamat. Klien memasukkan alamat IPv4 miliknya di bidang ini jika dan hanya jika klien memiliki alamat IPv4 yang valid saat dalam keadaan terikat; jika tidak, ini akan menyetel bidang ke 0.

  • Alamat IP Anda- Digunakan oleh server untuk menetapkan alamat IPv4 ke klien.

  • Alamat IP Server- Digunakan oleh server untuk mengidentifikasi alamat server yang harus digunakan klien untuk langkah selanjutnya dalam proses bootstrap, yang mungkin merupakan server yang mengirimkan balasan ini atau tidak. Server pengirim selalu menyertakan alamat IPv4 miliknya di kolom khusus yang disebut opsi Server Identifier DHCPv4.

  • Alamat IP Gerbang- Merutekan pesan DHCPv4 ketika agen relai DHCPv4 terlibat. Alamat gateway memfasilitasi komunikasi permintaan dan balasan DHCPv4 antara klien dan server yang berada di subnet atau jaringan berbeda.

  • Alamat Perangkat Keras Klien- Menentukan lapisan fisik klien.

  • Nama Server- Digunakan oleh server yang mengirimkan pesan DHCPOFFER atau DHCPACK. Server secara opsional dapat memasukkan namanya di bidang ini. Ini bisa berupa nama panggilan teks sederhana atau nama domain DNS, seperti dhcpserver.netacad.net.

  • Nama File Boot- Secara opsional digunakan oleh klien untuk meminta jenis file boot tertentu dalam pesan DHCPDISCOVER. Digunakan oleh server di DHCPOFFER untuk sepenuhnya menentukan direktori file boot dan nama file.

  • Opsi DHCP- Menyimpan opsi DHCP, termasuk beberapa parameter yang diperlukan untuk pengoperasian DHCP dasar. Bidang ini panjangnya bervariasi. Klien dan server dapat menggunakan bidang ini.
