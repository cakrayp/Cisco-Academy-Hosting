Protokol Konfigurasi Host Dinamis v4

Operasi DHCPv4

Jika klien dikonfigurasi untuk menerima pengaturan IPv4 secara dinamis dan ingin bergabung dengan jaringan, klien akan meminta nilai pengalamatan dari server DHCPv4. Klien mengirimkan pesan DHCPDISCOVER di jaringan lokalnya saat melakukan booting atau merasakan koneksi jaringan aktif. Karena klien tidak mempunyai cara untuk mengetahui subnet miliknya, pesan DHCPDISCOVER adalah siaran IPv4 (alamat IPv4 tujuan 255.255.255.255). Klien belum memiliki alamat IPv4 yang dikonfigurasi, sehingga alamat IPv4 sumber 0.0.0.0 digunakan.

Seperti yang ditunjukkan pada Gambar 1, alamat IPv4 klien (CIADDR), alamat gateway default (GIADDR), dan subnet mask semuanya ditandai untuk menunjukkan bahwa alamat 0.0.0.0 digunakan.

Catatan: Informasi tidak diketahui dikirim sebagai 0.0.0.0.

Ketika server DHCPv4 menerima pesan DHCPDISCOVER, server akan merespons dengan pesan DHCPOFFER. Pesan ini berisi informasi konfigurasi awal untuk klien, termasuk alamat IPv4 yang ditawarkan server, subnet mask, durasi sewa, dan alamat IPv4 server DHCPv4 yang memberikan penawaran.

Pesan DHCPOFFER dapat dikonfigurasi untuk menyertakan informasi lain, seperti waktu perpanjangan sewa dan alamat DNS.

Seperti yang ditunjukkan pada Gambar 2, server DHCP merespons DHCPDISCOVER dengan memberikan nilai ke CIADDR dan subnet mask. Bingkai dibuat menggunakan alamat perangkat keras klien (CHADDR) dan dikirim ke klien yang meminta.

Klien dan server mengirim pesan pengakuan, dan prosesnya selesai.
