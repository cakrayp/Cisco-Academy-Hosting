Protokol Konfigurasi Host Dinamis v4

Konfigurasikan Klien DHCPv4

Terkadang, router Cisco di kantor kecil/kantor rumah (SOHO) dan situs cabang harus dikonfigurasi sebagai klien DHCPv4 dengan cara yang mirip dengan komputer klien. Metode yang digunakan tergantung pada ISP. Namun, dalam konfigurasi paling sederhana, antarmuka Ethernet digunakan untuk menyambung ke modem kabel atau DSL. Untuk mengkonfigurasi antarmuka Ethernet sebagai klien DHCP, gunakanalamat ip dhcpperintah mode konfigurasi antarmuka.

Pada Gambar 1, asumsikan bahwa ISP telah dikonfigurasi untuk memberikan alamat IP kepada pelanggan terpilih dari rentang jaringan 209.165.201.0/27. Setelah antarmuka G0/1 dikonfigurasi denganalamat ip dhcpperintah, itutampilkan antarmuka ip g0/1perintah mengonfirmasi bahwa antarmuka sudah aktif dan alamat telah dialokasikan oleh server DHCPv4.

Gunakan Pemeriksa Sintaks pada Gambar 2 untuk mengkonfigurasi antarmuka yang terhubung ke ISP untuk memperoleh alamat dari server DHCP.
