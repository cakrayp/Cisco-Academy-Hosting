Protokol Konfigurasi Host Dinamis v4

Pecahkan masalah DHCPv4

Pada router yang dikonfigurasi sebagai server DHCPv4, proses DHCPv4 gagal jika router tidak menerima permintaan dari klien. Sebagai tugas pemecahan masalah, verifikasi bahwa router menerima permintaan DHCPv4 dari klien. Langkah pemecahan masalah ini melibatkan konfigurasi ACL untuk keluaran debug.

Gambar tersebut menunjukkan ACL yang diperluas hanya mengizinkan paket dengan port tujuan UDP 67 atau 68. Ini adalah port umum yang digunakan oleh klien dan server DHCPv4 saat mengirim pesan DHCPv4. ACL yang diperluas digunakan denganmen-debug paket ipperintah untuk hanya menampilkan pesan DHCPv4.

Output pada gambar menunjukkan bahwa router menerima permintaan DHCP dari klien. Alamat IP sumber adalah 0.0.0.0 karena klien belum memiliki alamat IP. Tujuannya adalah 255.255.255.255 karena pesan penemuan DHCP dari klien dikirim sebagai siaran. Output ini hanya menampilkan ringkasan paket dan bukan pesan DHCPv4 itu sendiri. Namun demikian, router menerima paket siaran dengan IP sumber dan tujuan serta port UDP yang benar untuk DHCPv4. Output debug lengkap menunjukkan semua paket dalam komunikasi DHCPv4 antara server DHCPv4 dan klien.

Perintah lain yang berguna untuk memecahkan masalah operasi DHCPv4 adalahmen-debug acara server ip dhcpmemerintah. Perintah ini melaporkan kejadian server, seperti penetapan alamat dan pembaruan basis data. Ini juga digunakan untuk mendekode penerimaan dan transmisi DHCPv4.
