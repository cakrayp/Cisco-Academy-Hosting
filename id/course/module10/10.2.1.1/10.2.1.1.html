Protokol Konfigurasi Host Dinamis v6

SLAAC dan DHCPv6

Mirip dengan IPv4, alamat unicast global IPv6 dapat dikonfigurasi secara manual atau dinamis. Namun, ada dua metode di mana alamat unicast global IPv6 dapat ditetapkan secara dinamis:

  • Konfigurasi Otomatis Alamat Tanpa Status (SLAAC), seperti yang ditunjukkan pada gambar

  • Protokol Konfigurasi Host Dinamis untuk IPv6 (Stateful DHCPv6)

Memperkenalkan SLAAC

SLAAC adalah metode di mana perangkat dapat memperoleh alamat unicast global IPv6 tanpa layanan server DHCPv6. Inti dari SLAAC adalah ICMPv6. ICMPv6 mirip dengan ICMPv4 tetapi mencakup fungsionalitas tambahan dan merupakan protokol yang jauh lebih kuat. SLAAC menggunakan pesan ICMPv6 Router Solicitation dan Router Advertisement untuk memberikan pengalamatan dan informasi konfigurasi lainnya yang biasanya disediakan oleh server DHCP:

  • Pesan Permintaan Router (RS).- Ketika klien dikonfigurasi untuk mendapatkan informasi pengalamatan secara otomatis menggunakan SLAAC, klien mengirimkan pesan RS ke router. Pesan RS dikirim ke alamat multicast semua router IPv6 FF02::2.

  • Pesan Iklan Router (RA).- Pesan RA dikirim oleh router untuk memberikan informasi pengalamatan kepada klien yang dikonfigurasi untuk mendapatkan alamat IPv6 mereka secara otomatis. Pesan RA menyertakan awalan dan panjang awalan segmen lokal. Klien menggunakan informasi ini untuk membuat alamat unicast global IPv6 miliknya sendiri. Router mengirimkan pesan RA secara berkala, atau sebagai respons terhadap pesan RS. Secara default, router Cisco mengirim pesan RA setiap 200 detik. Pesan RA selalu dikirim ke alamat multicast semua node IPv6 FF02::1.

Sesuai dengan namanya, SLAAC tidak memiliki kewarganegaraan. Layanan tanpa kewarganegaraan berarti tidak ada server yang menyimpan informasi alamat jaringan. Tidak seperti DHCP, tidak ada server SLAAC yang mengetahui alamat IPv6 mana yang digunakan dan mana yang tersedia.
