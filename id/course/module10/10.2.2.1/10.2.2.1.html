Protokol Konfigurasi Host Dinamis v6

DHCPv6 tanpa kewarganegaraan

Seperti yang ditunjukkan pada Gambar 1, ada empat langkah untuk mengkonfigurasi router sebagai server DHCPv6:

Langkah 1. Aktifkan Perutean IPv6

Gunakanperutean unicast ipv6perintah diperlukan untuk mengaktifkan perutean IPv6. Perintah ini tidak diperlukan agar router menjadi server DHCPv6 stateless, namun diperlukan untuk mengirim pesan ICMPv6 RA.

Langkah 2. Konfigurasikan Kumpulan DHCPv6

Itukumpulan dhcp ipv6nama kolamperintah membuat kumpulan dan memasuki router dalam mode konfigurasi DHCPv6, yang diidentifikasi olehRouter(config-dhcpv6)#mengingatkan.

Langkah 3. Konfigurasikan Parameter Kumpulan

Selama proses SLAAC klien menerima informasi yang diperlukan untuk membuat alamat unicast global IPv6. Klien juga menerima informasi gateway default menggunakan alamat IPv6 sumber dari pesan RA, yang merupakan alamat link-lokal router. Namun, server DHCPv6 stateless dapat dikonfigurasi untuk memberikan informasi lain yang mungkin tidak disertakan dalam pesan RA seperti alamat server DNS dan nama domain.

Langkah 4. Konfigurasikan Antarmuka DHCPv6

Ituserver dhcp ipv6nama kolamperintah mode konfigurasi antarmuka mengikat kumpulan DHCPv6 ke antarmuka. Router merespons permintaan DHCPv6 stateless pada antarmuka ini dengan informasi yang terdapat dalam kumpulan. Bendera O perlu diubah dari 0 menjadi 1 menggunakan perintah antarmukaipv6 dan bendera konfigurasi lainnya. Pesan RA yang dikirim pada antarmuka ini menunjukkan bahwa informasi tambahan tersedia dari server DHCPv6 stateless.

Contoh Server Tanpa Status DHCPv6

Gambar 2 menunjukkan contoh konfigurasi router yang akan dikonfigurasi sebagai server DHCPv6 stateless. Perhatikan bahwa router R3 ditampilkan sebagai klien DHCPv6. R3 dikonfigurasi sebagai klien untuk membantu memverifikasi operasi DHCPv6 stateless.
