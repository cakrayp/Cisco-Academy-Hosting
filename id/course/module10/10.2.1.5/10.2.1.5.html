Protokol Konfigurasi Host Dinamis v6

SLAAC dan DHCPv6

Meskipun DHCPv6 mirip dengan DHCPv4 dalam hal penyediaannya, kedua protokol tersebut tidak bergantung satu sama lain. DHCPv6 didefinisikan dalam RFC 3315. Ada banyak pekerjaan yang dilakukan pada spesifikasi ini selama bertahun-tahun sebagaimana ditunjukkan oleh fakta bahwa DHCPv6 RFC memiliki jumlah revisi tertinggi dari semua rancangan Internet.

Opsi DHCPv6 Tanpa Status (Iklan Router dan DHCPv6)

Opsi DHCPv6 stateless memberi tahu klien untuk menggunakan informasi dalam pesan RA untuk pengalamatan, namun parameter konfigurasi tambahan tersedia dari server DHCPv6.

Menggunakan awalan dan panjang awalan dalam pesan RA, bersama dengan EUI-64 atau IID yang dibuat secara acak, klien membuat alamat unicast global IPv6.

Klien kemudian akan berkomunikasi dengan server DHCPv6 stateless untuk mendapatkan informasi tambahan yang tidak disediakan dalam pesan RA. Ini mungkin daftar alamat IPv6 server DNS, misalnya. Proses ini dikenal sebagai DHCPv6 tanpa kewarganegaraan karena server tidak menyimpan informasi status klien apa pun (yaitu daftar alamat IPv6 yang tersedia dan dialokasikan). Server DHCPv6 stateless hanya menyediakan parameter konfigurasi untuk klien, bukan alamat IPv6.

Untuk DHCPv6 stateless, flag O diatur ke 1 dan flag M dibiarkan pada pengaturan default 0. Nilai flag O 1 digunakan untuk memberi tahu klien bahwa informasi konfigurasi tambahan tersedia dari server DHCPv6 stateless.

Untuk mengubah pesan RA yang dikirim pada antarmuka router agar menunjukkan DHCPv6 tanpa kewarganegaraan, gunakan perintah berikut:

Router(konfigurasi-jika)# ipv6 dan bendera konfigurasi lainnya
