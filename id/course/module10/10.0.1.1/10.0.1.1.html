Perkenalan

Setiap perangkat yang terhubung ke jaringan memerlukan alamat IP unik. Administrator jaringan menetapkan alamat IP statis ke router, server, printer, dan perangkat jaringan lainnya yang lokasinya (fisik dan logis) tidak mungkin berubah. Biasanya ini adalah perangkat yang menyediakan layanan kepada pengguna dan perangkat di jaringan; oleh karena itu, alamat yang diberikan kepada mereka harus tetap konstan. Selain itu, alamat statis memungkinkan administrator mengelola perangkat ini dari jarak jauh. Lebih mudah bagi administrator jaringan untuk mengakses perangkat ketika mereka dapat dengan mudah menentukan alamat IP-nya.

Namun, komputer dan pengguna dalam suatu organisasi sering berpindah lokasi, secara fisik dan logis. Mungkin sulit dan memakan waktu bagi administrator untuk menetapkan alamat IP baru setiap kali seorang karyawan berpindah. Selain itu, bagi karyawan lapangan yang bekerja dari lokasi terpencil, mengatur parameter jaringan yang benar secara manual dapat menjadi tantangan. Bahkan untuk klien desktop, penetapan alamat IP dan informasi pengalamatan lainnya secara manual menimbulkan beban administratif, terutama seiring dengan pertumbuhan jaringan.

Memperkenalkan server Dynamic Host Configuration Protocol (DHCP) ke jaringan lokal menyederhanakan penetapan alamat IP ke desktop dan perangkat seluler. Menggunakan server DHCP terpusat memungkinkan organisasi untuk mengelola semua penetapan alamat IP dinamis dari satu server. Praktik ini menjadikan pengelolaan alamat IP lebih efektif dan memastikan konsistensi di seluruh organisasi, termasuk kantor cabang.

DHCP tersedia untuk IPv4 (DHCPv4) dan untuk IPv6 (DHCPv6). Bab ini membahas fungsionalitas, konfigurasi, dan pemecahan masalah DHCPv4 dan DHCPv6.
