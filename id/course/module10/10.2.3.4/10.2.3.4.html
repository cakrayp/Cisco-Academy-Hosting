Protokol Konfigurasi Host Dinamis v6

Server DHCPv6 berstatus

Jika server DHCPv6 terletak di jaringan yang berbeda dari klien, maka router IPv6 dapat dikonfigurasi sebagai agen relai DHCPv6. Konfigurasi agen relai DHCPv6 mirip dengan konfigurasi router IPv4 sebagai relai DHCPv4.

Catatan: Meskipun konfigurasi agen relai DHCPv6 mirip dengan DHCPv4, router IPv6 atau agen relai meneruskan pesan DHCPv6 sedikit berbeda dari relai DHCPv4. Pesan dan prosesnya berada di luar cakupan kurikulum ini.

Gambar 1 menunjukkan contoh topologi di mana server DHCPv6 terletak di jaringan 2001:DB8:CAFE:1::/64. Administrator jaringan ingin menggunakan server DHCPv6 ini sebagai server DHCPv6 stateful pusat untuk mengalokasikan alamat IPv6 ke semua klien. Oleh karena itu, klien di jaringan lain seperti PC1 pada jaringan 2001:DB8:CAFE:A::/64, harus berkomunikasi dengan server DHCPv6.

Pesan DHCPv6 dari klien dikirim ke alamat multicast IPv6 FF02::1:2. Alamat All_DHCPv6_Relay_Agents_and_Servers. Alamat ini memiliki cakupan link-local yang berarti router tidak meneruskan pesan-pesan ini. Router harus dikonfigurasi sebagai agen relai DHCPv6 agar klien dan server DHCPv6 dapat berkomunikasi.

Mengonfigurasi Agen Relai DHCPv6

Seperti yang ditunjukkan pada Gambar 2, agen relai DHCPv6 dikonfigurasi menggunakantujuan relai dhcp ipv6memerintah. Perintah ini dikonfigurasi pada antarmuka yang menghadap klien DHCPv6 menggunakan alamat server DHCPv6 sebagai tujuan.

Itutampilkan antarmuka ipv6 dhcpperintah memverifikasi antarmuka G0/0 dalam mode relai dengan 2001:DB8:CAFE:1::6 dikonfigurasi sebagai server DHCPv6.

Dengan menggunakan Pemeriksa Sintaks pada Gambar 3, konfigurasikan perintah relai DHCPv6 pada router yang benar sehingga PC3 dapat menerima informasi pengalamatan IPv6 dari server DHCPv6. Lihat Gambar 1 untuk melihat topologi jaringan.
