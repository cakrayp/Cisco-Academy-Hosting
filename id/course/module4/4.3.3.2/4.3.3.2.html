Pengoperasian Perute

Rute yang Dipelajari Secara Statis

Gambar 1 menunjukkan konfigurasi rute statis default IPv4 pada R1 ke antarmuka Serial 0/0/0. Perhatikan bahwa konfigurasi rute menghasilkan 'S*' masuk dalam tabel routing. 'S' menandakan bahwa sumber rute adalah rute statis sedangkan tanda bintang (*) mengidentifikasi rute ini sebagai kandidat yang memungkinkan untuk menjadi rute default. Bahkan, telah dipilih sebagai rute default yang dibuktikan dengan baris yang bertuliskan, “Gateway of Last Resort is 0.0.0.0 to network 0.0.0.0.”

Gambar 2 menunjukkan konfigurasi dua rute statis dari R2 untuk mencapai dua LAN di R1. Rute ke 192.168.10.0/24 telah dikonfigurasi menggunakan antarmuka keluar sedangkan rute ke 192.168.11.0/24 telah dikonfigurasi menggunakan alamat IPv4 hop berikutnya. Meskipun keduanya dapat diterima, ada beberapa perbedaan dalam cara pengoperasiannya. Misalnya, perhatikan betapa berbedanya tampilannya di tabel perutean. Perhatikan juga bahwa karena rute statis ini ditujukan ke jaringan tertentu, outputnya menunjukkan bahwa Gateway of Last Resort tidak disetel.

Catatan: Rute statis statis dan default dibahas secara rinci di bab berikutnya.

Gunakan Pemeriksa Sintaks pada Gambar 3 untuk mengkonfigurasi rute statis default pada router R1 menuju R2.

Gunakan Pemeriksa Sintaks pada Gambar 4 untuk mengkonfigurasi rute statis pada router R2 untuk mencapai LAN R1.
