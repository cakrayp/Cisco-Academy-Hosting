Rute yang Dipelajari Secara Statis

Seperti IPv4, IPv6 mendukung rute statis statis dan default. Mereka digunakan dan dikonfigurasi seperti rute statis IPv4.

Untuk mengonfigurasi rute IPv6 statis default, gunakanrute ipv6 ::/0{alamat ipv6|nomor antarmuka tipe antarmuka}perintah konfigurasi global.

Gambar 1 menunjukkan konfigurasi rute statis default pada R1 ke antarmuka Serial 0/0/0.

Perhatikan pada output yang ditunjukkan pada Gambar 2 bahwa konfigurasi rute statis default menghasilkan 'S' masuk dalam tabel routing. 'S' menandakan bahwa sumber rute adalah rute statis. Berbeda dengan rute statis IPv4, tidak ada tanda bintang (*) atau Gateway of Last Resort yang diidentifikasi secara eksplisit.

Seperti IPv4, rute statis adalah rute yang dikonfigurasi secara eksplisit untuk menjangkau jaringan jarak jauh tertentu. Rute IPv6 statis dikonfigurasi menggunakanrute ipv6awalan ipv6/panjang awalan{alamat ipv6|nomor antarmuka tipe antarmuka}perintah konfigurasi global.

Contoh pada Gambar 3 menunjukkan konfigurasi dua rute statis dari R2 untuk mencapai dua LAN di R1. Rute ke LAN 2001:0DB8:ACAD:2::/64 dikonfigurasi dengan antarmuka keluar, sedangkan rute ke LAN 2001:0DB8:ACAD:1::/64 dikonfigurasi dengan alamat IPv6 hop berikutnya. Alamat IPv6 hop berikutnya dapat berupa alamat IPv6 global unicast atau link-local.

Gambar 4 menunjukkan tabel routing dengan rute statis baru yang diinstal.

Gambar 5 mengkonfirmasi konektivitas jaringan jarak jauh ke LAN 2001:0DB8:ACAD:4::/64 di R2 dari R1.
