Konfigurasi Awal Router

Hubungkan Perangkat

Perangkat jaringan dan pengguna akhir biasanya terhubung ke jaringan menggunakan Ethernet kabel atau koneksi nirkabel. Lihat gambar sebagai contoh topologi referensi. LAN pada gambar berfungsi sebagai contoh bagaimana pengguna dan perangkat jaringan dapat terhubung ke jaringan.

Perangkat kantor rumah dapat terhubung sebagai berikut:

  • Laptop dan tablet terhubung secara nirkabel ke router rumah.

  • Printer jaringan terhubung menggunakan kabel Ethernet ke port switch pada router rumah.

  • Router rumah terhubung ke modem kabel penyedia layanan menggunakan kabel Ethernet.

  • Modem kabel terhubung ke jaringan penyedia layanan Internet (ISP).

Perangkat situs Cabang terhubung sebagai berikut:

  • Sumber daya perusahaan (yaitu, server file dan printer) terhubung ke switch Layer 2 menggunakan kabel Ethernet.

  • PC desktop dan telepon voice over IP (VoIP) terhubung ke switch Layer 2 menggunakan kabel Ethernet.

  • Laptop dan ponsel cerdas terhubung secara nirkabel ke titik akses nirkabel (WAP).

  • WAP terhubung ke switch menggunakan kabel Ethernet.

  • Sakelar lapisan 2 terhubung ke antarmuka Ethernet di router tepi menggunakan kabel Ethernet. Router tepi adalah perangkat yang berada di tepi atau batas jaringan dan merutekan antara jaringan tersebut dan jaringan lainnya, seperti antara LAN dan WAN.

  • Router tepi terhubung ke penyedia layanan WAN (SP).

  • Router edge juga terhubung ke ISP untuk tujuan pencadangan.

Perangkat situs Pusat terhubung sebagai berikut:

  • PC Desktop dan telepon VoIP terhubung ke switch Layer 2 menggunakan kabel Ethernet.

  • Sakelar lapisan 2 terhubung secara redundan ke sakelar lapisan 3 multilapis menggunakan kabel serat optik Ethernet (koneksi oranye).

  • Sakelar multilapis lapisan 3 terhubung ke antarmuka Ethernet di router tepi menggunakan kabel Ethernet.

  • Server situs web perusahaan terhubung menggunakan kabel Ethernet ke antarmuka router edge.

  • Router tepi terhubung ke WAN SP.

  • Router edge juga terhubung ke ISP untuk tujuan pencadangan.

Di LAN Cabang dan Pusat, host terhubung baik secara langsung atau tidak langsung (melalui WAP) ke infrastruktur jaringan menggunakan switch Layer 2.
