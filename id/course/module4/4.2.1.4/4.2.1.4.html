Keputusan Perutean

Peralihan Paket Antar Jaringan

Proses berikut terjadi ketika R2 menerima frame pada antarmuka Fa0/0:

1. R2 memeriksa alamat MAC tujuan, yang cocok dengan alamat MAC antarmuka penerima, FastEthernet 0/0. Oleh karena itu, R2 menyalin frame ke dalam buffernya.

2. R2 mengidentifikasi bidang Tipe Ethernet sebagai 0x800, yang berarti frame Ethernet berisi paket IPv4 di bagian data frame.

3. R2 mendeenkapsulasi frame Ethernet.

4. Karena alamat IPv4 tujuan paket tidak cocok dengan alamat antarmuka R2 mana pun, R2 berkonsultasi dengan tabel peruteannya untuk merutekan paket ini. R2 mencari tabel perutean untuk alamat IPv4 tujuan paket menggunakan proses yang sama dengan yang digunakan R1.

Tabel perutean R2 memiliki rute ke jaringan 192.168.4.0/24, dengan alamat IPv4 hop berikutnya 192.168.3.2 dan antarmuka keluar Serial 0/0/0. Karena antarmuka keluar bukan jaringan Ethernet, R2 tidak harus menyelesaikan alamat IPv4 hop berikutnya dengan alamat MAC tujuan.

5. Paket IPv4 sekarang dienkapsulasi ke dalam bingkai data link baru dan mengirimkan antarmuka keluar Serial 0/0/0.

Ketika antarmuka adalah koneksi serial point-to-point (P2P), router merangkum paket IPv4 ke dalam format bingkai data link yang sesuai yang digunakan oleh antarmuka keluar (HDLC, PPP, dll.). Karena tidak ada alamat MAC pada antarmuka serial, R2 menetapkan alamat tujuan data link setara dengan siaran.
