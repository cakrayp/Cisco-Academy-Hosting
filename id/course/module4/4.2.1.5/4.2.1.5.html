Peralihan Paket Antar Jaringan

Proses berikut terjadi ketika frame tiba di R3:

1. R3 menyalin frame data link PPP ke dalam buffernya.

2. R3 mendeenkapsulasi frame PPP data link.

3. R3 mencari tabel routing untuk alamat IPv4 tujuan paket. Tabel routing memiliki rute ke jaringan yang terhubung langsung di R3. Artinya paket bisa langsung dikirim ke perangkat tujuan dan tidak perlu dikirim ke router lain.

Karena antarmuka keluar adalah jaringan Ethernet yang terhubung langsung, R3 harus menyelesaikan alamat IPv4 tujuan paket dengan alamat MAC tujuan:

1. R3 mencari alamat IPv4 tujuan paket dalam cache Address Resolusi Protocol (ARP). Jika entri tidak ada dalam cache ARP, R3 mengirimkan permintaan ARP dari antarmuka FastEthernet 0/0. PC2 mengirimkan kembali balasan ARP dengan alamat MAC-nya. R3 kemudian memperbarui cache ARP-nya dengan entri 192.168.4.10 dan alamat MAC yang dikembalikan dalam balasan ARP.

2. Paket IPv4 dienkapsulasi ke dalam bingkai data link Ethernet baru dan mengirimkan antarmuka FastEthernet 0/0 dari R3.

3. Ketika PC2 menerima frame, PC2 memeriksa alamat MAC tujuan, yang cocok dengan alamat MAC antarmuka penerima, kartu antarmuka jaringan Ethernet (NIC). Oleh karena itu, PC2 menyalin sisa frame ke dalam buffernya.

4. PC2 mengidentifikasi bidang Tipe Ethernet sebagai 0x800, yang berarti frame Ethernet berisi paket IPv4 di bagian data frame.

5. PC2 mendeenkapsulasi frame Ethernet dan meneruskan paket IPv4 ke proses IPv4 pada sistem operasinya.
