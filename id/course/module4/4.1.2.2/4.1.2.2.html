Konfigurasi Awal Router

Hubungkan Perangkat

Untuk mengaktifkan akses jaringan, perangkat harus dikonfigurasi dengan informasi alamat IP untuk mengidentifikasi yang sesuai:

  • alamat IP- Mengidentifikasi host unik di jaringan lokal.

  • Subnetmask- Mengidentifikasi subnet jaringan mana yang dapat berkomunikasi dengan host.

  • Gerbang bawaan- Mengidentifikasi router untuk mengirim paket ketika tujuannya tidak berada pada subnet jaringan lokal yang sama.

Ketika sebuah host mengirimkan paket ke perangkat yang berada di jaringan IP yang sama, paket tersebut hanya diteruskan keluar dari antarmuka host ke perangkat tujuan.

Ketika sebuah host mengirimkan paket ke perangkat di jaringan IP yang berbeda, maka paket tersebut diteruskan ke gateway default, karena perangkat host tidak dapat berkomunikasi langsung dengan perangkat di luar jaringan lokal. Gateway default adalah tujuan yang merutekan lalu lintas dari jaringan lokal ke perangkat di jaringan jarak jauh. Ini sering digunakan untuk menghubungkan jaringan lokal ke Internet.

Default gateway biasanya merupakan alamat antarmuka pada router yang terhubung ke jaringan lokal. Router memelihara entri tabel routing dari semua jaringan yang terhubung serta entri jaringan jarak jauh, dan menentukan jalur terbaik untuk mencapai tujuan tersebut.

Misalnya, jika PC1 mengirim paket ke Server Web yang terletak di 176.16.1.99, ia akan menemukan bahwa Server Web tidak berada di jaringan lokal dan oleh karena itu, harus mengirim paket ke alamat Media Access Control (MAC) dari gateway defaultnya. Unit data protokol paket (PDU) pada gambar mengidentifikasi alamat IP dan MAC sumber dan tujuan.

Catatan: Sebuah router juga biasanya dikonfigurasi dengan gateway defaultnya sendiri. Hal ini terkadang dikenal sebagai Gerbang Pilihan Terakhir.
