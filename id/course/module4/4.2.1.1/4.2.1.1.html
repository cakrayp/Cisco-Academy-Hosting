Peralihan Paket Antar Jaringan

Fungsi utama router adalah meneruskan paket menuju tujuannya. Hal ini dicapai dengan menggunakan fungsi switching, yaitu proses yang digunakan oleh router untuk menerima paket pada satu antarmuka dan meneruskannya keluar dari antarmuka lain. Tanggung jawab utama dari fungsi switching adalah untuk merangkum paket dalam tipe frame data link yang sesuai untuk data link keluar.

Catatan: Dalam konteks ini, istilah “switching” secara harfiah berarti memindahkan paket dari sumber ke tujuan dan berbeda dengan fungsi switch Layer 2.

Setelah router menentukan antarmuka keluar menggunakan fungsi penentuan jalur, router harus merangkum paket ke dalam bingkai data link dari antarmuka keluar.

Apa yang dilakukan router terhadap paket yang diterima dari satu jaringan dan ditujukan ke jaringan lain? Router melakukan tiga langkah utama berikut:

Langkah 1.De-enkapsulasi paket Layer 3 dengan menghapus header dan trailer frame Layer 2.

Langkah 2.Memeriksa alamat IP tujuan paket IP untuk menemukan jalur terbaik dalam tabel routing.

Langkah 3.Jika router menemukan jalur ke tujuan, ia merangkum paket Layer 3 ke dalam frame Layer 2 baru dan meneruskan frame tersebut keluar antarmuka keluar.

Seperti yang ditunjukkan pada gambar, perangkat memiliki alamat IPv4 Layer 3 dan antarmuka Ethernet memiliki alamat tautan data Layer 2. Misalnya, PC1 dikonfigurasi dengan alamat IPv4 192.168.1.10 dan contoh alamat MAC 0A-10. Saat paket berpindah dari perangkat sumber ke perangkat tujuan akhir, alamat IP Layer 3 tidak berubah. Namun, alamat data link Layer 2 berubah pada setiap hop saat paket dide-enkapsulasi dan dienkapsulasi ulang dalam frame baru oleh setiap router. Sangat mungkin bahwa paket tersebut dienkapsulasi dalam jenis bingkai Layer 2 yang berbeda dari yang diterimanya. Misalnya, frame yang dienkapsulasi Ethernet mungkin diterima oleh router pada antarmuka FastEthernet, dan kemudian diproses untuk diteruskan keluar dari antarmuka serial sebagai frame yang dienkapsulasi Point-to-Point Protocol (PPP).
