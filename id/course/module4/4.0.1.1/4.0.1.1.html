Konsep Perutean

Perkenalan

Jaringan memungkinkan orang untuk berkomunikasi, berkolaborasi, dan berinteraksi dalam banyak cara. Jaringan digunakan untuk mengakses halaman web, berbicara menggunakan telepon IP, berpartisipasi dalam konferensi video, berkompetisi dalam permainan interaktif, berbelanja menggunakan Internet, menyelesaikan kursus online, dan banyak lagi.

Switch Ethernet berfungsi pada lapisan data link, Layer 2, dan digunakan untuk meneruskan frame Ethernet antar perangkat dalam jaringan yang sama.

Namun, ketika IP sumber dan alamat IP tujuan berada di jaringan yang berbeda, frame Ethernet harus dikirim ke router.

Router menghubungkan satu jaringan ke jaringan lain. Router bertanggung jawab atas pengiriman paket melalui jaringan yang berbeda. Tujuan paket IP mungkin adalah server web di negara lain atau server email di jaringan area lokal.

Router menggunakan tabel routingnya untuk menentukan jalur terbaik yang digunakan untuk meneruskan paket. Merupakan tanggung jawab router untuk mengirimkan paket-paket tersebut secara tepat waktu. Efektivitas komunikasi internetwork sangat bergantung pada kemampuan router untuk meneruskan paket dengan cara seefisien mungkin.

Ketika sebuah host mengirimkan paket ke perangkat di jaringan IP yang berbeda, paket tersebut diteruskan ke gateway default karena perangkat host tidak dapat berkomunikasi secara langsung dengan perangkat di luar jaringan lokal. Gateway default adalah tujuan yang merutekan lalu lintas dari jaringan lokal ke perangkat di jaringan jarak jauh. Ini sering digunakan untuk menghubungkan jaringan lokal ke Internet.

Bab ini juga akan menjawab pertanyaan, “Apa yang dilakukan router terhadap paket yang diterima dari satu jaringan dan ditujukan ke jaringan lain?” Detail tabel routing akan diperiksa termasuk rute terhubung, statis, dan dinamis.

Karena router dapat merutekan paket antar jaringan, perangkat di jaringan berbeda dapat berkomunikasi. Bab ini akan memperkenalkan router, perannya dalam jaringan, komponen perangkat keras dan perangkat lunak utamanya, dan proses routing. Latihan yang mendemonstrasikan cara mengakses router, mengkonfigurasi pengaturan dasar router, dan memverifikasi pengaturan akan disediakan.
