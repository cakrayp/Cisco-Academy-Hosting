Konfigurasi Awal Router

Hubungkan Perangkat

Perangkat infrastruktur jaringan memerlukan alamat IP untuk mengaktifkan manajemen jarak jauh. Dengan menggunakan alamat IP perangkat, administrator jaringan dapat terhubung ke perangkat dari jarak jauh menggunakan Telnet, SSH, HTTP, atau HTTPS.

Switch tidak memiliki antarmuka khusus yang dapat diberikan alamat IP. Sebaliknya, informasi alamat IP dikonfigurasikan pada antarmuka virtual yang disebut antarmuka virtual yang diaktifkan (SVI).

Misalnya, pada Gambar 1, SVI pada switch Layer 2 S1 diberi alamat IP 192.168.10.2/24 dan gateway default router terletak di 192.168.10.1.

Gunakan Pemeriksa Sintaks pada Gambar 2 untuk mengkonfigurasi saklar Layer 2 S2.
