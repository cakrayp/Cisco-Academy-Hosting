Konfigurasi Awal Router

Hubungkan Perangkat

Sebuah host dapat diberikan informasi alamat IP:

  • Secara statis- Host secara manual diberi alamat IP, subnet mask, dan gateway default yang benar. Alamat IP server DNS juga dapat dikonfigurasi.

  • Secara dinamis- Informasi alamat IP disediakan oleh server menggunakan Dynamic Host Configuration Protocol (DHCP). Server DHCP menyediakan alamat IP yang valid, subnet mask, dan gateway default untuk perangkat akhir. Informasi lain mungkin disediakan oleh server.

Gambar 1 dan Gambar 2 memberikan contoh konfigurasi alamat IPv4 statis dan dinamis.

Alamat yang ditetapkan secara statis biasanya digunakan untuk mengidentifikasi sumber daya jaringan tertentu, seperti server jaringan dan printer. Mereka juga dapat digunakan di jaringan yang lebih kecil dengan sedikit host. Namun, sebagian besar perangkat host memperoleh informasi alamat IPv4 dengan mengakses server DHCP. Di perusahaan besar, server DHCP khusus diterapkan yang menyediakan layanan ke banyak LAN. Di cabang yang lebih kecil atau kantor kecil, layanan DHCP dapat disediakan oleh switch Cisco Catalyst atau Cisco ISR.
