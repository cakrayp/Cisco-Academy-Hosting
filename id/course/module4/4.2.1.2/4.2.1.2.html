Peralihan Paket Antar Jaringan

Dalam animasi pada gambar, PC1 mengirimkan paket ke PC2. PC1 harus menentukan apakah alamat IPv4 tujuan berada di jaringan yang sama. PC1 menentukan subnetnya sendiri dengan melakukanDANoperasi pada alamat IPv4 dan subnet masknya sendiri. Ini menghasilkan alamat jaringan milik PC1. Selanjutnya, PC1 melakukan hal yang samaDANoperasi menggunakan alamat IPv4 tujuan paket dan subnet mask PC1.

Jika alamat jaringan tujuan sama dengan jaringan PC1, maka PC1 tidak menggunakan default gateway. Sebaliknya, PC1 mengacu pada cache ARP-nya untuk alamat MAC perangkat dengan alamat IPv4 tujuan tersebut. Jika alamat MAC tidak ada dalam cache, maka PC1 menghasilkan permintaan ARP untuk memperoleh alamat guna menyelesaikan paket dan mengirimkannya ke tujuan. Jika alamat jaringan tujuan berada di jaringan yang berbeda, maka PC1 meneruskan paket tersebut ke gateway defaultnya.

Untuk menentukan alamat MAC gateway default, PC1 memeriksa tabel ARP untuk alamat IPv4 gateway default dan alamat MAC yang terkait.

Jika entri ARP tidak ada dalam tabel ARP untuk gateway default, PC1 mengirimkan permintaan ARP. Router R1 mengirimkan kembali balasan ARP. PC1 kemudian dapat meneruskan paket ke alamat MAC gateway default, antarmuka Fa0/0 router R1.

Proses serupa digunakan untuk paket IPv6. Alih-alih proses ARP, resolusi alamat IPv6 menggunakan pesan ICMPv6 Neighbor Solicitation dan Neighbor Advertisement. Pemetaan alamat IPv6-ke-MAC disimpan dalam tabel yang mirip dengan cache ARP, yang disebut cache tetangga.
