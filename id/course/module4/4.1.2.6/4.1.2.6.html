Konfigurasi Awal Router

Hubungkan Perangkat

Dalam lingkungan produksi, perangkat infrastruktur biasanya diakses dari jarak jauh menggunakan Secure Shell (SSH) atau HyperText Transfer Protocol Secure (HTTPS). Akses konsol sebenarnya hanya diperlukan saat pertama kali mengonfigurasi perangkat, atau jika akses jarak jauh gagal.

Akses konsol memerlukan:

  • Kabel konsol- Kabel konsol RJ-45-ke-DB-9

  • Perangkat lunak emulasi terminal- Jangka Tera, Putty, HyperTerminal

Kabel terhubung antara port serial host dan port konsol pada perangkat. Sebagian besar komputer dan notebook tidak lagi dilengkapi port serial bawaan. Jika host tidak memiliki port serial, port USB dapat digunakan untuk membuat koneksi konsol. Adaptor port serial khusus yang kompatibel dengan USB-ke-RS-232 diperlukan saat menggunakan port USB.

Cisco ISR G2 mendukung koneksi konsol serial USB. Untuk menjalin konektivitas, diperlukan USB Tipe-A ke USB Tipe-B (USB mini-B), serta driver perangkat sistem operasi. Driver perangkat ini tersedia dariwww.cisco.com. Meskipun router ini memiliki dua port konsol, hanya satu port konsol yang dapat aktif dalam satu waktu. Saat kabel dicolokkan ke port konsol USB, port RJ-45 menjadi tidak aktif. Ketika kabel USB dicabut dari port USB, port RJ-45 menjadi aktif.

Tabel pada Gambar 1 merangkum persyaratan koneksi konsol. Gambar 2 menampilkan berbagai port dan kabel yang dibutuhkan.
