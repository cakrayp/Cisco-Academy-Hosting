Fungsi Router

Bagaimana mengklik link di browser web mengembalikan informasi yang diinginkan hanya dalam hitungan detik? Meskipun ada banyak perangkat dan teknologi yang bekerja sama untuk mewujudkan hal ini, perangkat utamanya adalah router. Sederhananya, router menghubungkan satu jaringan ke jaringan lainnya.

Komunikasi antar jaringan tidak akan mungkin terjadi tanpa router menentukan jalur terbaik ke tujuan dan meneruskan lalu lintas ke router berikutnya di sepanjang jalur tersebut. Router bertanggung jawab atas perutean lalu lintas antar jaringan.

Pada animasi pada gambar, diagram topologi jaringan terdiri dari dua host, dua switch dan Cisco 1841 Integrated Series Router (ISR).

Ketika sebuah paket tiba di antarmuka router, router menggunakan tabel peruteannya untuk menentukan cara mencapai jaringan tujuan. Tujuan paket IP mungkin adalah server web di negara lain atau server email di jaringan area lokal. Merupakan tanggung jawab router untuk mengirimkan paket-paket tersebut secara efisien. Efektivitas komunikasi internetwork sangat bergantung pada kemampuan router untuk meneruskan paket dengan cara seefisien mungkin.
