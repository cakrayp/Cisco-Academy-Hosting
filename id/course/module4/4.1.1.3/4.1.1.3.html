Konfigurasi Awal Router

Fungsi Router

Sebagian besar perangkat berkemampuan jaringan (yaitu komputer, tablet, dan ponsel cerdas) memerlukan komponen berikut untuk beroperasi, seperti yang ditunjukkan pada Gambar 1:

  • Unit pemrosesan pusat (CPU)

  • Sistem operasi (OS)

  • Memori dan penyimpanan (RAM, ROM, NVRAM, Flash, hard drive)

Router pada dasarnya adalah komputer khusus. Dibutuhkan CPU dan memori untuk menyimpan data sementara dan permanen untuk menjalankan instruksi sistem operasi, seperti inisialisasi sistem, fungsi perutean, dan fungsi peralihan.

Catatan: Perangkat Cisco menggunakan Cisco Internetwork Operating System (IOS) sebagai perangkat lunak sistem.

Tabel pada Gambar 2 merangkum jenis memori router, volatilitas, dan contoh apa yang disimpan di masing-masing memori.

Router menyimpan data menggunakan:

  • Memori Akses Acak (RAM)- Menyediakan penyimpanan sementara untuk berbagai aplikasi dan proses termasuk IOS yang sedang berjalan, file konfigurasi yang sedang berjalan, berbagai tabel (yaitu, tabel routing IP, tabel Ethernet ARP) dan buffer untuk pemrosesan paket. RAM disebut volatil karena kehilangan isinya ketika listrik dimatikan.

  • Memori Hanya-Baca (ROM)- Menyediakan penyimpanan permanen untuk instruksi bootup, perangkat lunak diagnostik dasar, dan IOS terbatas jika router tidak dapat memuat IOS berfitur lengkap. ROM merupakan firmware dan disebut non-volatile karena tidak kehilangan isinya ketika listrik dimatikan.

  • Memori Akses Acak Non-Volatil (NVRAM)- Menyediakan penyimpanan permanen untuk file konfigurasi startup (startup-config). NVRAM bersifat non-volatile dan tidak kehilangan isinya saat listrik dimatikan.

  • Kilatan- Menyediakan penyimpanan permanen untuk IOS dan file terkait sistem lainnya. IOS disalin dari flash ke RAM selama proses bootup. Flash bersifat non-volatile dan tidak kehilangan isinya saat listrik dimatikan.

Berbeda dengan komputer, router tidak memiliki adaptor video atau adaptor kartu suara. Sebaliknya, router memiliki port khusus dan kartu antarmuka jaringan untuk menghubungkan perangkat ke jaringan lain. Gambar 3 mengidentifikasi beberapa port dan antarmuka ini.
