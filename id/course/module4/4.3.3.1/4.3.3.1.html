Rute yang Dipelajari Secara Statis

Setelah antarmuka yang terhubung langsung dikonfigurasi dan ditambahkan ke tabel perutean, maka perutean statis atau dinamis dapat diimplementasikan.

Rute statis dikonfigurasi secara manual. Mereka menentukan jalur eksplisit antara dua perangkat jaringan. Berbeda dengan protokol perutean dinamis, rute statis tidak diperbarui secara otomatis dan harus dikonfigurasi ulang secara manual jika topologi jaringan berubah. Manfaat menggunakan rute statis mencakup peningkatan keamanan dan efisiensi sumber daya. Rute statis menggunakan bandwidth lebih sedikit dibandingkan protokol routing dinamis, dan tidak ada siklus CPU yang digunakan untuk menghitung dan mengkomunikasikan rute. Kerugian utama menggunakan rute statis adalah kurangnya konfigurasi ulang otomatis jika topologi jaringan berubah.

Ada dua tipe umum rute statis dalam tabel routing:

  • Rute statis ke jaringan tertentu

  • Rute statis default

Rute statis dapat dikonfigurasi untuk menjangkau jaringan jarak jauh tertentu. Rute statis IPv4 dikonfigurasi menggunakanrute iptopeng jaringan {hop-ip berikutnya | keluar-intf}perintah konfigurasi global. Rute statis diidentifikasi dalam tabel routing dengan kode 'S’.

Rute statis default mirip dengan gateway default pada host. Rute statis default menentukan titik keluar yang akan digunakan ketika tabel perutean tidak berisi jalur untuk jaringan tujuan.

Rute statis default berguna ketika router hanya memiliki satu titik keluar ke router lain, misalnya saat router terhubung ke router pusat atau penyedia layanan.

Untuk mengonfigurasi rute statis default IPv4, gunakanrute ip 0.0.0.0 0.0.0.0 {keluar-intf | hop-ip berikutnya} perintah konfigurasi global.
