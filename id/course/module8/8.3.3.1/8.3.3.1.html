Verifikasi OSPFv3

Gunakantampilkan tetangga ospf ipv6perintah untuk memverifikasi bahwa router telah membentuk kedekatan dengan router tetangganya. Jika ID router dari router tetangga tidak ditampilkan, atau jika tidak ditampilkan dalam keadaan FULL, kedua router belum membentuk kedekatan OSPF.

Jika dua router tidak membangun kedekatan tetangga, informasi link-state tidak dipertukarkan. LSDB yang tidak lengkap dapat menyebabkan pohon SPF dan tabel perutean tidak akurat. Rute ke jaringan tujuan mungkin tidak ada atau mungkin bukan jalur yang paling optimal.

Gambar 1 menampilkan kedekatan tetangga R1. Untuk setiap tetangga, perintah ini menampilkan keluaran berikut:

  • ID Tetangga- ID router dari router tetangga.

  • Pri- Prioritas antarmuka OSPF. Nilai digunakan dalam pemilihan DR dan BDR.

  • Negara- Status antarmuka OSPF. Status LENGKAP berarti router dan tetangganya memiliki OSPF LSDB yang identik. Pada jaringan multiakses seperti Ethernet, dua router yang berdekatan mungkin menampilkan statusnya sebagai 2WAY. Tanda hubung menunjukkan bahwa DR atau BDR tidak diperlukan karena jenis jaringan.

  • Waktu Mati- Jumlah waktu yang tersisa di mana router menunggu untuk menerima paket OSPF Hello dari tetangganya sebelum mendeklarasikan tetangganya down. Nilai ini direset ketika antarmuka menerima paket Hello.

  • ID Antarmuka- ID antarmuka atau ID tautan.

  • Antarmuka- Antarmuka tempat router ini membentuk kedekatan dengan tetangganya.

Gunakan Pemeriksa Sintaks pada Gambar 2 untuk memverifikasi tetangga R2 dan R3 menggunakantampilkan tetangga ospf ipv6memerintah.
