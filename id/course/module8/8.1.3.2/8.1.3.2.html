Karakteristik OSPF

Operasi OSPF

Ketika OSPF diaktifkan pada sebuah antarmuka, router harus menentukan apakah ada tetangga OSPF lain pada link tersebut. Untuk mencapai hal ini, router meneruskan paket Hello yang berisi ID routernya ke semua antarmuka yang mendukung OSPF. ID router OSPF digunakan oleh proses OSPF untuk mengidentifikasi secara unik setiap router di area OSPF. ID router adalah alamat IP yang ditetapkan untuk mengidentifikasi router tertentu di antara rekan-rekan OSPF.

Ketika router tetangga yang mendukung OSPF menerima paket Hello dengan ID router yang tidak ada dalam daftar tetangganya, router penerima mencoba untuk membangun kedekatan dengan router yang memulai.

Lihat R1 pada Gambar 1. Saat OSPF diaktifkan, antarmuka Gigabit Ethernet 0/0 yang diaktifkan bertransisi dari status Bawah ke status Init. R1 mulai mengirimkan paket Hello ke semua antarmuka yang mendukung OSPF untuk menemukan tetangga OSPF untuk mengembangkan adjacency.

Pada Gambar 2, R2 menerima paket Hello dari R1 dan menambahkan ID router R1 ke daftar tetangganya. R2 kemudian mengirimkan paket Hello ke R1. Paket tersebut berisi ID Router R2 dan ID Router R1 dalam daftar tetangganya pada antarmuka yang sama.

Pada Gambar 3, R1 menerima Hello dan menambahkan ID Router R2 dalam daftar tetangga OSPF-nya. Ia juga memperhatikan ID Routernya sendiri di daftar tetangga paket Hello. Ketika router menerima paket Hello dengan ID Router-nya tercantum dalam daftar tetangga, router bertransisi dari status Init ke status Dua Arah.

Tindakan yang dilakukan dalam keadaan Dua Arah bergantung pada jenis interkoneksi antara router yang berdekatan:

  • Jika dua tetangga yang berdekatan saling terhubung melalui link point-to-point, maka mereka segera bertransisi dari keadaan Dua Arah ke fase sinkronisasi database.

  • Jika router saling terhubung melalui jaringan Ethernet umum, maka router DR dan BDR yang ditunjuk harus dipilih.

Karena R1 dan R2 saling berhubungan melalui jaringan Ethernet, pemilihan DR dan BDR terjadi. Seperti terlihat pada Gambar 4, R2 menjadi DR dan R1 menjadi BDR. Proses ini hanya terjadi pada jaringan multi-akses seperti LAN Ethernet.

Paket Hello terus dipertukarkan untuk menjaga informasi router.
