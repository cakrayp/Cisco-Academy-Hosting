Mengonfigurasi OSPFv2 Area Tunggal

ID Perute OSPF

Setiap router memerlukan ID router untuk berpartisipasi dalam domain OSPF. ID router dapat ditentukan oleh administrator atau ditetapkan secara otomatis oleh router. ID router digunakan oleh router yang mendukung OSPF untuk:

  • Identifikasi router secara unik- ID router digunakan oleh router lain untuk mengidentifikasi secara unik setiap router dalam domain OSPF dan semua paket yang berasal darinya.

  • Ikut serta dalam pemilihan DR- Dalam lingkungan LAN multiakses, pemilihan DR terjadi pada saat awal pembentukan jaringan OSPF. Ketika link OSPF menjadi aktif, perangkat routing yang dikonfigurasi dengan prioritas tertinggi dipilih sebagai DR. Dengan asumsi tidak ada prioritas yang dikonfigurasi, atau ada seri, maka router dengan ID router tertinggi dipilih sebagai DR. Perangkat perutean dengan ID router tertinggi kedua dipilih sebagai BDR.

Tapi bagaimana cara router menentukan ID router? Seperti yang diilustrasikan dalam gambar, router Cisco memperoleh ID router berdasarkan salah satu dari tiga kriteria, dalam urutan preferensi berikut:

  • ID router dikonfigurasi secara eksplisit menggunakan OSPFrouter-idmenyingkirkanperintah mode konfigurasi router. Itumenyingkirkanvalue adalah nilai 32-bit apa pun yang dinyatakan sebagai alamat IPv4. Ini adalah metode yang disarankan untuk menetapkan ID router.

  • Jika ID router tidak dikonfigurasi secara eksplisit, router memilih alamat IPv4 tertinggi dari semua antarmuka loopback yang dikonfigurasi. Ini adalah alternatif terbaik berikutnya untuk menetapkan ID router.

  • Jika tidak ada antarmuka loopback yang dikonfigurasi, maka router memilih alamat IPv4 aktif tertinggi dari semua antarmuka fisiknya. Ini adalah metode yang paling tidak direkomendasikan karena mempersulit administrator untuk membedakan router tertentu.

Jika router menggunakan alamat IPv4 tertinggi untuk ID router, antarmuka tidak perlu mengaktifkan OSPF. Artinya alamat antarmuka tidak perlu dicantumkan dalam salah satu OSPFjaringanperintah agar router menggunakan alamat IP tersebut sebagai ID router. Satu-satunya persyaratan adalah antarmuka aktif dan dalam keadaan aktif.

Catatan: ID router terlihat seperti alamat IP, namun tidak dapat dirutekan dan, oleh karena itu, tidak disertakan dalam tabel perutean, kecuali proses perutean OSPF memilih antarmuka (fisik atau loopback) yang ditentukan dengan tepat oleh ajaringanmemerintah.
