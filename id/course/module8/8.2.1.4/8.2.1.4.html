Mengonfigurasi OSPFv2 Area Tunggal

ID Perute OSPF

Gunakanrouter-idmenyingkirkanperintah mode konfigurasi router untuk secara manual menetapkan nilai 32-bit yang dinyatakan sebagai alamat IPv4 ke router. Router OSPF mengidentifikasi dirinya ke router lain menggunakan ID router ini.

Seperti yang ditunjukkan pada Gambar 1, R1 dikonfigurasi dengan ID router 1.1.1.1, R2 dengan 2.2.2.2, dan R3 dengan 3.3.3.3.

Pada Gambar 2, ID router 1.1.1.1 ditetapkan ke R1. Gunakantampilkan protokol ipperintah untuk memverifikasi ID router.

Catatan: R1 belum pernah dikonfigurasi dengan ID router OSPF. Jika ya, maka ID router harus diubah.

Jika ID router sama pada dua router tetangga, router akan menampilkan pesan kesalahan seperti di bawah ini:

%OSPF-4-DUP_RTRID1: Router terdeteksi dengan ID router duplikat.

Untuk memperbaiki masalah ini, konfigurasikan semua router sehingga mereka memiliki ID router OSPF yang unik.

Gunakan Pemeriksa Sintaks pada Gambar 3 untuk menetapkan ID router ke R2 dan R3.
