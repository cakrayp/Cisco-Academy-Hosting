Konfigurasikan OSPFv3 Area Tunggal

Mengonfigurasi OSPFv3

Gunakanrouter ipv6 ospfproses-idperintah mode konfigurasi global untuk masuk ke mode konfigurasi router. Prompt mode konfigurasi router IPv6 berbeda dengan prompt mode konfigurasi router IPv4. Gunakan mode konfirmasi router IPv6 untuk mengonfigurasi parameter OSPFv3 global, seperti menetapkan ID router OSPF 32-bit dan bandwidth referensi.

Protokol perutean IPv6 diaktifkan pada antarmuka, dan bukan dari mode konfigurasi router, seperti protokol IPv4. ItujaringanPerintah mode konfigurasi router IPv4 tidak ada di IPv6.

Seperti OSPFv2, ituproses-idnilainya adalah angka antara 1 dan 65.535 dan dipilih oleh administrator jaringan. Ituproses-idnilainya signifikan secara lokal, yang berarti bahwa ia tidak harus cocok dengan router OSPF lain untuk membangun kedekatan dengan tetangganya.

OSPFv3 memerlukan ID router 32-bit untuk ditetapkan sebelum OSPF dapat diaktifkan pada antarmuka. Diagram logika pada Gambar 1 menampilkan bagaimana ID router dipilih. Seperti OSPFv2, OSPFv3 menggunakan:

  • ID router yang dikonfigurasi secara eksplisit terlebih dahulu.

  • Jika tidak ada yang dikonfigurasi, maka router menggunakan alamat IPv4 terkonfigurasi tertinggi dari antarmuka loopback.

  • Jika tidak ada yang dikonfigurasi, maka router menggunakan alamat IPv4 terkonfigurasi tertinggi dari antarmuka aktif.

  • Jika tidak ada sumber alamat IPv4 pada router, maka router menampilkan pesan konsol untuk mengkonfigurasi ID router secara manual.

Catatan: Untuk konsistensi, ketiga router menggunakan ID proses 10.

Seperti yang ditunjukkan dalam topologi pada Gambar 2, router R1, R2, dan R3 akan diberi ID router yang ditunjukkan. Iturouter-idmenyingkirkanperintah yang digunakan untuk menetapkan ID router di OSPFv2 adalah perintah yang sama yang digunakan di OSPFv3.

Contoh pada Gambar 3:

  • Memasuki mode konfigurasi OSPFv3 router. Perhatikan bagaimana prompt router berbeda dari prompt router mode protokol perutean IPv4 default. Perhatikan juga bagaimana pesan konsol informasi muncul ketika mode konfigurasi router OSPFv3 diakses.

  • Menetapkan ID router 1.1.1.1.

  • Menyesuaikan bandwidth referensi menjadi 1.000.000.000 bps (1 Gb/s), karena terdapat tautan Gigabit Ethernet di jaringan. Perhatikan pesan konsol informasi bahwa perintah ini harus dikonfigurasi pada semua router di domain perutean.

  • Itutampilkan protokol ipv6perintah digunakan untuk memverifikasi bahwa proses OSPFv3 ID 10 menggunakan ID router 1.1.1.1.

Gunakan Pemeriksa Sintaks pada Gambar 4 untuk mengonfigurasi pengaturan OSPFv3 global pada R2 dan R3.
