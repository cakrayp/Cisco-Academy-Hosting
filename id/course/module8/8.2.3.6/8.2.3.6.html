Mengonfigurasi OSPFv2 Area Tunggal

Biaya OSPF

Sebagai alternatif untuk mengatur bandwidth antarmuka default, biaya dapat dikonfigurasi secara manual pada antarmuka menggunakanbiaya ip ospfnilaiperintah konfigurasi antarmuka.

Keuntungan mengkonfigurasi biaya dibandingkan mengatur bandwidth antarmuka adalah bahwa router tidak perlu menghitung metrik ketika biaya dikonfigurasi secara manual. Sebaliknya, ketika bandwidth antarmuka dikonfigurasi, router harus menghitung biaya OSPF berdasarkan bandwidth. Itubiaya ip ospfPerintah ini berguna dalam lingkungan multi-vendor di mana router non-Cisco dapat menggunakan metrik selain bandwidth untuk menghitung biaya OSPF.

Keduanyalebar pitaperintah antarmuka danbiaya ip ospfperintah antarmuka mencapai hasil yang sama, yaitu memberikan nilai akurat untuk digunakan oleh OSPF dalam menentukan rute terbaik.

Misalnya, dalam contoh di Gambar 1, bandwidth antarmuka serial 0/0/1 diatur ulang ke nilai default dan biaya OSPF diatur secara manual ke 15,625. Meskipun bandwidth antarmuka diatur ulang ke nilai default, biaya OSPF diatur seolah-olah bandwidth masih dihitung.

Gambar 2 menunjukkan dua alternatif yang dapat digunakan dalam memodifikasi biaya link serial dalam topologi. Sisi kanan gambar menunjukkanbiaya ip ospfperintah yang setara denganlebar pitaperintah di sebelah kiri.
