Karakteristik OSPF

Buka Jalur Terpendek Terlebih Dahulu

Semua protokol perutean berbagi komponen serupa. Mereka semua menggunakan pesan protokol perutean untuk bertukar informasi rute. Pesan tersebut membantu membangun struktur data, yang kemudian diproses menggunakan algoritma perutean.

Tiga komponen utama dari protokol routing OSPF meliputi:

Struktur Data

OSPF membuat dan memelihara tiga database: (lihat Gambar 1).

  • Basis data kedekatan- Membuat tabel tetangga

  • Basis data status tautan (LSDB)- Membuat tabel topologi

  • Basis data penerusan- Membuat tabel routing

Tabel ini berisi daftar router tetangga untuk bertukar informasi routing dan disimpan serta dipelihara dalam RAM.

Pesan Protokol Perutean

OSPF bertukar pesan untuk menyampaikan informasi routing menggunakan lima jenis paket. Paket-paket ini, seperti yang ditunjukkan pada Gambar 2, adalah:

  • Halo paket

  • Paket deskripsi basis data

  • Paket permintaan status tautan

  • Paket pembaruan status tautan

  • Paket pengakuan status tautan

Paket-paket ini digunakan untuk menemukan router tetangga dan juga untuk bertukar informasi routing guna menjaga keakuratan informasi tentang jaringan.

Algoritma

CPU memproses tabel tetangga dan topologi menggunakan algoritma SPF Dijkstra. Algoritme SPF didasarkan pada biaya kumulatif untuk mencapai suatu tujuan.

Algoritma SPF membuat pohon SPF dengan menempatkan setiap router pada akar pohon dan menghitung jalur terpendek ke setiap node. Pohon SPF kemudian digunakan untuk menghitung rute terbaik. OSPF menempatkan rute terbaik ke dalam database penerusan, yang digunakan untuk membuat tabel routing.
