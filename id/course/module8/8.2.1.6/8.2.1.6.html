Mengonfigurasi OSPFv2 Area Tunggal

ID Perute OSPF

ID router juga dapat ditetapkan menggunakan antarmuka loopback.

Alamat IPv4 dari antarmuka loopback harus dikonfigurasi menggunakan subnet mask 32-bit (255.255.255.255). Ini secara efektif menciptakan rute host. Rute host 32-bit tidak diiklankan sebagai rute ke router OSPF lainnya.

Contoh pada gambar menampilkan cara mengkonfigurasi antarmuka loopback dengan rute host di R1. R1 menggunakan rute host sebagai ID routernya, dengan asumsi tidak ada ID router yang dikonfigurasi secara eksplisit atau dipelajari sebelumnya.

Catatan: Beberapa versi iOS yang lebih lama tidak mengenalinyarouter-idmemerintah; oleh karena itu, cara terbaik untuk mengatur ID router pada router tersebut adalah dengan menggunakan antarmuka loopback.
