Karakteristik OSPF

Pesan OSPF

Halo Paket

Paket OSPF Tipe 1 adalah paket Hello. Paket hello digunakan untuk:

  • Temukan tetangga OSPF dan buat kedekatan tetangga.

  • Iklankan parameter di mana dua router harus setuju untuk menjadi tetangga.

  • Pilih Designated Router (DR) dan Backup Designated Router (BDR) pada jaringan multiakses seperti Ethernet dan Frame Relay. Tautan point-to-point tidak memerlukan DR atau BDR.

Gambar tersebut menampilkan field yang terdapat dalam paket Hello Tipe 1. Bidang penting yang ditunjukkan pada gambar meliputi:

  • Jenis- Mengidentifikasi jenis paket. Angka satu (1) menunjukkan paket Hello. Nilai 2 mengidentifikasi paket DBD, 3 paket LSR, 4 paket LSU, dan 5 paket LSAck.

  • ID Perute- Nilai 32-bit yang dinyatakan dalam notasi desimal bertitik (alamat IPv4) yang digunakan untuk mengidentifikasi router asal secara unik.

  • ID Daerah- Area asal paket.

  • Masker Jaringan- Subnet mask yang terkait dengan antarmuka pengiriman.

  • Halo Interval- Menentukan frekuensi, dalam hitungan detik, saat router mengirimkan paket Hello. Interval Hello default pada jaringan multiakses adalah 10 detik. Pengatur waktu ini harus sama di router tetangga; jika tidak, kedekatan tidak akan terjalin.

  • Prioritas Router- Digunakan pada pemilu DR/BDR. Prioritas default untuk semua router OSPF adalah 1, namun dapat diubah secara manual dari 0 hingga 255. Semakin tinggi nilainya, semakin besar kemungkinan router menjadi DR pada link.

  • Interval Mati- Apakah waktu dalam hitungan detik dimana router menunggu kabar dari tetangganya sebelum menyatakan router tetangganya tidak dapat digunakan. Secara default, Interval Mati router adalah empat kali interval Hello. Pengatur waktu ini harus sama di router tetangga; jika tidak, kedekatan tidak akan terjalin.

  • Router yang Ditunjuk (DR)- ID Router dari DR.

  • Router Khusus Cadangan (BDR)- ID Router BDR.

  • Daftar Tetangga- Daftar yang mengidentifikasi ID router dari semua router yang berdekatan.

Klik masing-masing bidang yang disorot pada gambar untuk informasi lebih lanjut.
