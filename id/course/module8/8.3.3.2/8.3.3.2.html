Konfigurasikan OSPFv3 Area Tunggal

Verifikasi OSPFv3

Seperti yang ditunjukkan pada Gambar 1,tampilkan protokol ipv6perintah adalah cara cepat untuk memverifikasi informasi konfigurasi OSPFv3 yang penting, termasuk ID proses OSPF, ID router, dan antarmuka yang diaktifkan untuk OSPFv3.

Gunakan Pemeriksa Sintaks pada Gambar 2 untuk memverifikasi pengaturan protokol OSPF R2 dan R3 menggunakantampilkan protokol ipv6memerintah.

Gunakantampilkan ipv6 ospfperintah untuk juga memeriksa ID proses OSPFv3 dan ID router. Perintah ini menampilkan informasi area OSPF dan terakhir kali algoritma SPF dihitung.
