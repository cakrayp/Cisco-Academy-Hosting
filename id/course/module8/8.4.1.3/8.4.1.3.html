Ringkasan

Versi OSPF untuk IPv4 saat ini adalah OSPFv2 yang diperkenalkan di RFC 1247 dan diperbarui di RFC 2328 oleh John Moy. Pada tahun 1999, OSPFv3 untuk IPv6 diterbitkan di RFC 2740.

OSPF adalah protokol routing link-state tanpa kelas dengan jarak administratif default 110, dan dilambangkan dalam tabel routing dengan kode sumber rute sebesar O.

OSPF diaktifkan denganrouter ospfproses-idperintah mode konfigurasi global. Ituproses-idnilainya signifikan secara lokal, yang berarti bahwa ia tidak perlu mencocokkan router OSPF lain untuk membangun kedekatan dengan tetangganya.

Itujaringanperintah yang digunakan dengan OSPF memiliki fungsi yang sama seperti ketika digunakan dengan protokol routing IGP lainnya, namun dengan sintaks yang sedikit berbeda. Ituwildcard-masknilainya adalah kebalikan dari subnet mask, danarea-idnilai harus disetel ke 0.

Secara default, paket Hello OSPF dikirim setiap 10 detik pada segmen multiakses dan point-to-point dan setiap 30 detik pada segmen NBMA (Frame Relay, X.25, ATM), dan digunakan oleh OSPF untuk membangun kedekatan tetangga. Interval Mati adalah empat kali interval Halo, secara default.

Agar router dapat berdekatan, interval Hello, interval Mati, jenis jaringan, dan subnet masknya harus cocok. Gunakantampilkan ip ospf tetanggaperintah untuk memverifikasi kedekatan OSPF.

OSPF memilih DR untuk bertindak sebagai titik pengumpulan dan distribusi untuk LSA yang dikirim dan diterima dalam jaringan multiakses. BDR dipilih untuk mengambil peran DR jika DR gagal. Semua router lain dikenal sebagai DROTHER. Semua router mengirimkan LSA mereka ke DR, yang kemudian membanjiri LSA ke semua router lain di jaringan multiakses.

Itutampilkan protokol ipperintah ini digunakan untuk memverifikasi informasi konfigurasi OSPF yang penting, termasuk ID proses OSPF, ID router, dan jaringan yang diiklankan oleh router.

OSPFv3 diaktifkan pada antarmuka dan tidak dalam mode konfigurasi router. OSPFv3 memerlukan alamat link-lokal untuk dikonfigurasi. Perutean Unicast IPv6 harus diaktifkan untuk OSPFv3. ID router 32-bit diperlukan sebelum antarmuka dapat diaktifkan untuk OSPFv3.
