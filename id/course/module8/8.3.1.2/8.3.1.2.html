OSPFv2 vs OSPFv3

Seperti terlihat pada gambar, berikut persamaan OSPFv2 dan OSPFv3:

  • Status tautan- OSPFv2 dan OSPFv3 keduanya merupakan protokol routing link-state tanpa kelas.

  • Algoritma perutean- OSPFv2 dan OSPFv3 menggunakan algoritma SPF untuk membuat keputusan routing.

  • Metrik- RFC untuk OSPFv2 dan OSPFv3 mendefinisikan metrik sebagai biaya pengiriman paket keluar antarmuka. OSPFv2 dan OSPFv3 dapat dimodifikasi menggunakanbandwidth referensi biaya otomatisref-bwperintah mode konfigurasi router. Perintah ini hanya mempengaruhi metrik OSPF di mana ia dikonfigurasi. Misalnya, jika perintah ini dimasukkan untuk OSPFv3, ini tidak mempengaruhi metrik perutean OSPFv2.

  • Daerah- Konsep beberapa area di OSPFv3 sama dengan di OSPFv2. Multiarea yang meminimalkan banjir link-state dan memberikan stabilitas yang lebih baik dengan domain OSPF.

  • Jenis paket OSPF- OSPFv3 menggunakan lima tipe paket dasar yang sama seperti OSPFv2 (Hello, DBD, LSR, LSU, dan LSAck).

  • Mekanisme penemuan tetangga- Mesin negara tetangga, termasuk daftar negara tetangga OSPF dan kejadiannya, tetap tidak berubah. OSPFv2 dan OSPFv3 menggunakan mekanisme Hello untuk mempelajari router tetangga dan membentuk kedekatan. Namun, di OSPFv3, tidak ada persyaratan untuk mencocokkan subnet untuk membentuk kedekatan tetangga. Hal ini karena kedekatan tetangga dibentuk menggunakan alamat link-lokal, bukan alamat unicast global.

  • Proses pemilihan DR/BDR- Proses pemilihan DR/BDR tetap tidak berubah di OSPFv3.

  • ID Perute- OSPFv2 dan OSPFv3 menggunakan nomor 32-bit untuk ID router yang direpresentasikan dalam notasi desimal bertitik. Biasanya ini adalah alamat IPv4. OSPFrouter-idperintah harus digunakan untuk mengkonfigurasi ID router. Proses dalam menentukan Router ID 32-bit sama di kedua protokol. Gunakan ID router yang dikonfigurasi secara eksplisit; jika tidak, alamat IPv4 loopback tertinggi akan menjadi ID router.
