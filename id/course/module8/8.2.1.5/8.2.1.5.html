Mengonfigurasi OSPFv2 Area Tunggal

ID Perute OSPF

Terkadang ID router perlu diubah, misalnya, ketika administrator jaringan membuat skema ID router baru untuk jaringan. Namun, setelah router memilih ID router, router OSPF yang aktif tidak mengizinkan ID router diubah hingga router dimuat ulang atau proses OSPF dihapus.

Pada Gambar 1, perhatikan bahwa ID router saat ini adalah 192.168.10.5. ID router harus 1.1.1.1.

Pada Gambar 2, ID router 1.1.1.1 ditugaskan ke R1. Perhatikan bagaimana pesan informasi muncul yang menyatakan bahwa proses OSPF harus dihapus atau router harus dimuat ulang. Penyebabnya karena R1 sudah memiliki adjacency dengan tetangga lainnya yang menggunakan router ID 192.168.10.5. Kedekatan tersebut harus dinegosiasi ulang menggunakan IP router baru 1.1.1.1.

Menghapus proses OSPF adalah metode pilihan untuk mereset ID router.

Pada Gambar 3, proses perutean OSPF dibersihkan menggunakanhapus proses ip ospfperintah mode EXEC istimewa. Hal ini memaksa OSPF di R1 untuk bertransisi ke status Down dan Init. Perhatikan pesan perubahan kedekatan dari penuh ke bawah dan kemudian dari memuat ke penuh. Itutampilkan protokol ipperintah memverifikasi bahwa ID router telah berubah.

Gunakan Pemeriksa Sintaks pada Gambar 4 untuk mengubah ID router untuk R1.
